# RES-0173　安定な内部回転と、物質が受ける重力

2026-11-24。第5巻 O.5。条件付きの理論結果。[導出](../derivations/DER-0173.md)・[数値と形式検証](../verification/VER-0160.md)・[前回の不安定性](RES-0172.md)。

正四面体の回転で同一視する内部空間を使うと、CATの層内作用から**全ての古典的な開弦スカラーの変形に対して安定な半径**を導けた。局所的な一種類の弦端、非零の保存角運動量、平坦な四次元の条件である。同じ作用から求めたフェルミオン対の励起しきい値 \(4r\) は、重力による局所角速度の変化に追随する。そのため平衡状態では、遠くの時計から見ると、長波長の重力赤方偏移が消える。この励起だけで通常の時計の物理を説明することは難しい。

| 調べた作用と状態 | 物理的な判定 |
|---|---|
| 射影前の回転球と通常の物質 | 同じ記録を比較する層が全て同じ形に変わると、差だけを見るC4の復元力はゼロ。内部方向を運動する横波を正の数だけ等方的に加えても、遠心力を再計算すると静的な形の復元力は弱まる。 |
| 射影された単一部門 | 回転は全電荷固定のエネルギー最小状態。物質が圧縮されたときに伝わる位相の波は光速の \(1/\sqrt3\)。半径が直接及ぼす力の到達距離は \(1/(2r)\)。 |
| 同じ場所に置いた三種類の弦端 | 捩れた電荷を相殺する三種類を同じ半径・同じ回転向きにすると、いかなる位相の組合せにも振幅成長率が \(\lvert\omega\rvert/8\) 以上の波がある。その下限を達成する位相もある。反対向きでも周期的な増幅が生じた。離れた固定点で電荷の定数成分を相殺する配置は可能で、回転中の弦の実際の安定性は未確定。 |
| 均質な回転媒質を仮定した太陽系測定 | 時計と物質の質量の平衡感度を \(\sigma\) とする。普遍結合、準静的平衡、Einstein系に重力ポテンシャルの差がない場合、Cassiniから \(-1.20\times10^{-5}\lesssim\sigma\lesssim3.30\times10^{-5}\)。時計と軌道の比較だけでは両者に共通の感度は測れない。 |
| 重力定数も同じ半径に依存する場合 | \(F(r)R/2\) を含む四次の作用では \(b=M_P r/\sqrt F\) が測定できる質量を決める。\(b'\ne0\) の回転枝では平衡感度が1。孤立した \(b'=0\) なら角速度と \(b''\) の符号条件の下で半径を固定し、同じ物質への一次の力を消せる。 |
| 六つの静止行列から計算した二球 | 一ループの重力係数は実際に物質への力が消える点を持つ。両球が二次元表現の例では、一方の球を運動する粒子への力が消える点はエネルギーの斜面。対称な粒子への力が消える停留点は軸比に対して不安定。 |
| 同じ六方向で二球を実際に回す場合 | 内部同時回転で不変な四次元ゲージ波が、二つの回転の差周波数で励起される。無制限の連続波数を持つ古典作用では全ての非零の異周波数に増幅帯が存在する。静止時の中性比でも低次の成長を数値で検出した。 |

量子補正を求める際に必要なのは、同じ回転する背景での重力係数、半径の二階変分、実在する物質準位の応答である。どれか一つだけが他の真空で望ましい値を取っても、観測と両立するCATの半径を決めたことにはならない。
