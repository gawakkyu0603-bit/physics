# RES-0132　光を放った後に何が残り、着く前に何を捕獲できるか

2026-11-23。著者 Yohtaro Soga。条件付きの四次元自己重力解、電磁波の数値解、一励起有効理論での解析的制約。第二論文付録Z.16。[導出](../derivations/DER-0132.md)・[検証](../verification/VER-0120.md)・[文献](../literature/notes/material-shell-discharge.md)。

3太陽質量の球対称例で、Aは光子球から古典的特異点まで36.195 µsの固有時間を持つ。無限遠で静止した自由落下の初期条件を使用した。Bの外部で同じ入射準備から内向きの光を放つと、静止する受信面には物体より2.258 µs早く届く。ここで検査したのは相関を受け渡す物質であり、先着する光が全ての枝で重力的な電荷制約を起動するかは別途導く必要がある。

| 最終判定の一部 | 求まったこと | 残る条件 |
|---|---|---|
| 光と物質の脱出 | 自己重力を含め、最後の放出を真外向きに限ると静止親殻のADM質量の3/4が内向きに残る。斜めの放出では、外殻が逃げ、内殻も地平面候補の外で折り返し、再衝突せず両者が無限遠に届く開いた条件がある。 | 球対称で、各殻が接線方向にも運動する質量ゼロの粒子からなる。残った物質を通常の光へ変換する具体的な終端が要る。 |
| 物質が出す現実の波 | 荷電する表面スカラーの粒子・反粒子が角運動量をもつ光子へ消滅する。\(d=6,J=4\) の線は幾何光学では通るが、曲がった時空の波の応力を入れると反跳条件を外れる。\(d=20,J=14\) と \(d=26,J=18\) は小放出時の圧力条件を満たす。 | \(d\) は局所エネルギー差と半径の積。通った二線はホーキング温度の74倍と97倍にある。全球の放射スペクトルでも、単一光子の応力による厳密な球対称解でもない。 |
| 記録の読み出し | 固定した外部と一励起の近似で、明るい多重項が光と結合する強さを通常の電荷・球面電流から計算した。正の周波数に暗い成分がなく、束縛閾値も下回る場合、外部参照系との磁気量子数の相関が漸近的に光へ渡る。 | 受信面の反跳、永久記録、別の物質励起を同時に消去するわけではない。固定した静止解は動径方向に不安定。 |
| 同じ遷移による捕獲 | \(d=20,J=14\) に最適な単一光子を全天から入れても、2.258 µsで励起できる確率は0.7390%以下。多数の同じ受け手を置くと、最強モードの束縛回避と最弱モードの期限が競合する。\(d=26,J=18\) では、光子球から届く領域の結合比は \(7.59\times10^{-42}\)、必要値は0.16284。 | 周波数と角分布が分離した単一の多重項、均一な受信器、一点で始まる信号を仮定した。37方向のうち必要条件を通るのは最大5方向。そこに一光子で37次元すべてを符号化するなら、区別可能な時間・周波数モードが最低8つ要る。この構成で一つの受信面に全てを任せるなら、少なくとも \(4.4293\,r_s\) から信号を出す必要がある。 |
| 蒸発末期の放射量 | ホーキング放射の占有数を保ち、まだ送っていない37状態を角運動量18、エネルギーが温度の96.81倍以上の光だけで運ぶ場合、残存質量が既に約 \(3.79\times10^{11}\) kgを下回ってからでは光子数が足りない。終端までの質量を全て予算に算入した上限。 | 残存質量100万 kgの時点で、これ以前の放射と合わせて完全回収するには、以前の放射だけで既に量子もつれ忠実度の誤差が \(1.36\times10^{-11}\) 以下である必要がある。低周波への符号化や半古典近似を離れる終端は条件を変える。 | 
| 遅い読み出しを許す場合 | 先に落下物が当たる範囲だけを閉じ、後で記録を半球へ配れれば、同じ角運動量をもつ全磁気量子数の幾何学的な結合は等しくなる。 | この二段階を自然に起動する作用、蓄積中の安定性、外部質量の減少と完全なホーキング放射への移送は未導出。 |

以上から、この受信器を親作用の選択条件に格上げする最終判定は満たされていない。Aの私的な最終事実と、Bが受信して保持した入射状態は最後に照合しない。
