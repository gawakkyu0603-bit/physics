# RES-0115　落下者と遠方の物質に実際に届く記録から、地平面の作用を絞る

2026-11-22。**CONDITIONAL**。第2論文に統合。新しい論文は作らず、Aが落下する宇宙とBが地平面だけを持つ宇宙を扱う付録Vを延長した。論文191頁・[日本語の導出](../derivations/DER-0115.md)・[検証](../verification/VER-0103.md)。

| 問い | 今回得られた答えと適用条件 |
|---|---|
| 同じAを、近いAと遠いBがどこまで知るか | 流体球の近くを通る一つの質量から、二者に蓄えられる四重極の角運動量を求めた。2つの鏡映軌道のどちらかを区別する例で、冷たいAの判定は高精度になる。1 pcのBが初期の波だけで軌道の向きを判断すると平均44.81%誤る。 |
| その差が運命にどう作用するか | 捕獲時に重力だけが物質の角運動量の差を読む拡張を定義した。受信条件を満たせばAには落下する物質の自由度があり、Bには地平面の自由度だけがAの状態を引き継ぐ。例の冷たいAが境界へ行く確率は \(1.1\times10^{-57}\) 未満、Bが境界へ行く確率は、最近接の信号が到着して約21時間後に0.9943。これは捕獲が起きた場合の確率である。 |
| 距離だけで決まるか | Bの物質がAの振動に共鳴すれば、同じ距離でも1受信年後の境界確率は0.478。Bの周波数を1%ずらすと約0.994に留まる。受け取った後で過去の捕獲に作用することはできない。 |
| 薄いAの振動をBの放射にそのまま使えるか | 自由落下で地平面横断時の変形を10%以下にするには \(\omega_fR_H/c\ge2.1482\)。同じ周波数を外部の四重極ポテンシャルの頂点に静止する時計で受け継ぐと、放射エネルギーは \(16.87\,k_BT_H\) 以上。典型的な熱帯に入れるには、最後に受けた光の赤方偏移を引き継ぐ候補、または多量子への変換が必要になる。 |
| 地平面から量子相関が戻るか | Bの外部時間を使い、未知の二モード状態の真空放出と熱雑音を含む候補を計算した。単一のGaussian経路に同温の入射口と灰色体障壁がある場合、参照系とのもつれが少しでも残るには物質寄与 \(w>e^{-\hbar\omega/(k_BT_H)}\) が必要。典型エネルギー \(y=1\) の単一波束に、例の流体の粘性を未回収のまま通常の重力放出だけを使う案はこの条件を満たさない。 |
| 層同士が直接影響できるか | 共存する二層が同じ軌道の角反跳を共有する仮説では、既に重力で書かれた電荷だけに \(H_{12}=q_1q_2/(\mu_r r^2)\) が作用する。通常の重力波を二層の間で伝える必要がない。反跳が独立な仮説ではこの項は消える。 |

**独自性と残る問題。** 潮汐吸収・相補性・熱チャネルはいずれも先行研究がある。今回加えたのは、物質がどれだけAについて知れるかを、重力捕獲時に幾何を選ぶ規則と結び、同じ物質の落下中の変形とBでの量子放出で選別すること。一般の崩壊物質が角運動量の基準を自然にどう用意するか、A自身と場の全ての相関を読む作用、境界の応力とスペクトル密度、四次元時空の非摂動的な測度は未同定である。数値は指定した物質と入力状態に対する比較である。[原著との照合](../literature/notes/tidal-receipts.md)・[作用の前段](RES-0114.md)。

**比較記録を要求しない候補 HYP-0006。** 既に生じた二層の重力反跳の差が、落下物質を通す共鳴をずらす作用を追加した。各層がどちらも厚くても、二つが一緒に動くと落下する。独立な場合は状態をBの地平面へ移せる。半古典的な熱エネルギーで二層が一つのモードだけを受け取ると、移送確率は強結合でも53.79%以下。六つの独立なモード対なら99%を超える例がある。受信の従来案とこの力学的な案を、共通の捕獲時間・エネルギー・無信号条件で比較した。準備済みの同じ状態を単に知らないだけでは、二層を物理的に独立にはできない。球対称の冷たい落下では、Aの身体が潮汐の静的平衡から遅れているかを読む規則が別天体なしで成立する。

**Bで落下確率が厳密にゼロになる候補。** 層間の反跳で落下側のスペクトルの下端が上がる場合、以前の重力捕獲で二層が受け取った量子の総数が奇数なら、反跳が一致する成分はない。入射余剰エネルギーがその最小シフトを下回る全帯域で、Bの地平面がAの状態全部を保持する。巨視的流体の通常の振動のギャップでは、このしきい値は小さすぎる。

層の相互作用の本文199頁・厳密な境界条件201頁。

**微視的作用。** 十一次元BFSSの行列の回転慣性と重力遷移電流、十次元の物理的な弦の頂点、四次元スピンフォームの参照付き電荷、因果集合・CDTの物質接触に、両機構の挿入を構成した。IIA強結合の第11次元を使う場合、円が開いても整数運動量の差と幅が固定なら効果が消える。LQGで全ベクトルの差を使うと、二つの等しいスピンを最大にそろえても \(2j\hbar^2\) が残る。どちらも薄い履歴を通すには微視的な幅との整合が必要である。
