# RES-0142　荷電面の有効作用を実現するBFSS型行列作用

2026-11-23。状態は **条件付きの親作用候補**。第4論文付録Sに統合した。原稿・[導出](../derivations/DER-0142.md)・[検証](../verification/VER-0130.md)・[原著23件との比較](../literature/notes/layer-matrix-parent.md)。赤外条件は[第2論文の前終端照合](RES-0141.md)。

従来の行列作用が作る物質の量子相関に、二段階の作用を加えた。実際に重力の反跳を受けた物質が、行列膜の向き付けられた交差で補償電荷を受け取る。その電荷が、同じ場所に届いた他の層の電荷とともに、一つの落下振幅が通れるかを決める。永久記録は受信時の物質モードの選択として実現し、Aの未知の状態は選択されたBの物質・放射へそのまま運べる。層間に通常の重力波が伝搬する項は用いない。

| 選別した性質 | 導けた範囲と条件 |
|---|---|
| Aの落下とBの表面 | 全ての実在する受信端に共通する断面を使う。近傍で個々の電荷が不確かでも、相対電荷が正確なら通路は開く。一方、正の割合を占める両立不能な端が入って共通核が消えれば、Bの内部への振幅は厳密に零になる。普通の有限回のサンプリングや認識上の無知だけではこの結論は出ない。 |
| 通常の重力が受信器を準備する一例 | 回転膜の質量四重極は回転周波数の2倍で放射し、別の行列膜でスピン1の横揺らぎを二つ作れる。等しい半径で共鳴し、外部の共鳴時計は不要。6周期の弱いパルスでは半径比1で 0.00026644、比1.18でほぼ0.000000100。占有端からの確実な電荷移送と、その端を準備する確率の違いが定量的に出る。 |
| いつ何を選ぶか | 二重化した行列作用のジャンプでは、実際に届いた重力反跳の物質準位が、蓄えた電荷の値をボルン重みで選ぶ。単位交差で必ずいずれかの電荷を選ぶ界面作用も構成できる。受信器占有・交差を条件にすればこちらは書込み待ちを要しない。任意の落下物に対する到着確率は別の問題として残る。 |
| Bに残る識別情報 | 質量・エネルギーが異なる二つのAを外部基準ともつれさせても、受信器だけが同じエネルギーを放出する過程では忠実度1。全系の絶対初期エネルギーを隠れた履歴に残すと1/2に低下。エネルギー確率分布は丸ごと保存される。核と全放射が使える場合と、放射単独で回収が完了した場合を区別する。 |
| 16超電荷 | 正エネルギー・中心項なしで完全な多重項を用意すれば、不可逆項を全超電荷の絡作用素へ射影できる。一つの偏極だけの書込みは、256状態の長多重項で各成分の率が元のピークの1/65536になる。全多重項を同じように受け取る源では減衰しない。 |
| 四次元時空の候補 | コンパクト化行列弦で、行列調和関数から二つの角方向が現れる。時刻・円・球の四次元プローブ計量を導出。非回転収縮解は通常の優勢エネルギー条件に反する。回転する行列解にはこれを満たす圧力範囲があり、定常解では円方向に張力、角方向の圧力は零。巻き弦は所定の張力密度ならこれを支え得る。その密度とニュートン定数の導出は未完。 |
| ブラックホール放射で退けた候補 | 四電荷弦の中性外挿は面積エントロピーと軟スカラーの先頭係数を再現するが、裸の透過率が \(\omega/T_H=5.1351\) を超えると1より大きくなる。前終端域の有限周波数には補正が要る。全放射種の行列をこの親作用単独から導いた段階ではない。 |

十次元IIAの摂動弦・行列弦、十次元IIBのIKKT、十一次元 BFSS/M理論、四次元ループ重力、因果集合、CDTとの対応と障害は原稿最終節に具体化した。四次元の伝播には制御された大行列極限がある。観測に適合する一般の四次元アインシュタイン重力、自然物質の受信端、全蒸発を一つの模型から導くことは引き続き未解決である。
