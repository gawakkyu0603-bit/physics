# RES-0162　Einstein方程式を満たすCAT時空と、観測者・真空・微分構造

2026-11-24。第7巻T.10。DER-0162、VER-0149、PLAN-0119、DEC-0147。[数式と判定](../derivations/DER-0162.md)・[形式化・数値結果](../verification/VER-0149.md)・[原著](../literature/notes/cat-einstein-sectors.md)。

| 問い | 今回の判定 |
|---|---|
| 物質の波動方程式から得た計量は通常のGRを満たすか | 解に依存する。同じ作用の非平坦な真空平面波を明示した。一方、シュワルツシルト内部と曲率を合わせた球が、その後に有限面積で折り返す状態は、折返しで \(R_{\mu\nu}k^\mu k^\nu<0\)。真空・任意の宇宙定数・ヌルエネルギー条件を満たす物質だけでは通常のGRと合わない。 |
| 満たすよう構成できるか | 平坦解に加え、潮汐を持つ真空波ができる。半径一定の球は、独立にMaxwell方程式を満たす磁場と正の宇宙定数を合わせた通常のGRとも整合する。現実の一般物質についてGRを回収するには、同じ行列から物質応力・長距離の重力作用・十分な計量変分を導く必要がある。 |
| 特異点で時空を乗り換えたか | 同じ入射潮汐を持つ二つの計算は、異なる保存内部エネルギー（8928.97、9322.85）をもつ別々の初期状態。一つの時間発展で二時空の間を移ったとの証拠はない。準安定な幾何・真空を物理的に定め、一つの準備から異なる部門への非零遷移確率が出れば「乗り換え」を定義できる。 |
| 十という数、内部のローレンツ符号は変わるか | 現行CATの層内作用では十成分・内部一時間九空間を固定した。その上の厳密な行列解では、同じ台の物質の主部が、正定値、退化、一時間三空間のいずれにもなる。これは解を替えた比較。単一の歴史での署名変化は示していない。 |
| 同じ真空の観測者と異なる真空を区別できるか | 同じ準備でも物質に届いた記録が違えば条件付き状態は異なる。真空や相の差は観測者を替えても残る物理量・境界条件・量子表現で判定する。現段階で確かめたランドスケープは古典的な計量の多重性であり、安定な量子真空の分類は残る。 |
| エキゾチックな \(\mathbb R^4\) と対応するか | 球対称族の台は \(I\times\mathbb R\times S^2\) で別の位相。一方、平坦なCAT面を、標準 \(\mathbb R^4\) に埋め込まれた小さいエキゾチックな開集合に制限すれば、その上で半古典CAT方程式と真空Einstein方程式が両立する。これは同じ周囲の真空の異なる領域という実例。計量は不完備で大域的双曲性を欠き、完全な平行移動はその領域を保たない。独立な量子真空や観測者による自発的な領域選択は未導出。 |

折返しに必要な通常のGRとの差は定量化できる。動径光線の入射時のアフィン規格化を \(dR/d\lambda=-1\) とすると、最初の折返しまでの \(\int R R_{\mu\nu}k^\mu k^\nu\,d\lambda=-2\)。三つの行列解で、曲率を直接積分してこの値を再現した。これと同じ差を担う量子物質または量子重力項をCATから計算できれば、微分構造や真空遷移を仮定せずに内部の力学を判定できる。
