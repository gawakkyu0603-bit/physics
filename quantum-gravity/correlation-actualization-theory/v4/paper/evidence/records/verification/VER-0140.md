# VER-0140　全物理角モードと光線近傍の偏極を照合する

2026-11-24。RES-0153・DER-0153・PLAN-0110。[計算コード](../../workspace/code/cat_core_multiplet.py)・[数値基準表](../../workspace/verification/cat-core-multiplet-results.json)・[Leanの命題](../../workspace/verification/CATCoreMultiplet.lean)・[近縁の先行研究](../literature/notes/cat-core-multiplet.md)。

## 数値と独立な照合

プロジェクト直下で `python -B code/cat_core_multiplet.py` を実行する。依存はNumPy、SciPy。局所の六行列を復元する関数は[既存の時計計算](../../workspace/code/cat_singular_clock.py)と同じものを呼ぶ。乱数、指定外のファイル、観測データを要しない。行列単位、始終点、初期波動関数は[導出](../derivations/DER-0153.md)に従う。

| 対象 | 別の方法による確認 |
|---|---|
| 物理偏極の個数と固有値 | \(\ell=1,2,3,5\) でSU(2)行列を構成。二重交換子の直接展開とスピン1の合成でヘッセ行列を比較し、発散の核に数値射影して固有値を照合。フェルミオンのPauli演算子も直接対角化。 |
| 球面の量子逆作用 | 互いに異なる7個の \((j,g_1^2)\) で、最初の転回までDOP853で積分。61時点でボース全モードのWronskian、フェルミオンを含むエネルギー及び中心の通過時刻を確認。エネルギーの最大ずれは行列慣性当たり \(4\times10^{-11}\) 未満。 |
| 回転する球 | 三組のClifford行列で作るスピン回転とスピン \(\ell\) の角運動量から時間独立の回転枠Hamiltonianを直接対角化。五種類の \(\ell\) で、正準位の占有による仕事を、負の海も含む共分散の跡と比較。全時刻の解析的上限を超えないことを確認。 |
| 量子化した径 | 同じ \(\ell=1\) の径方向を二回数えない補正を施し、角塔ごとにボース・フェルミ零点係数の差を検査。指定したガウス状態の平均エネルギーと二次形式の下限から確率を評価。数表の値は上限であり実時間サンプリングの値ではない。 |
| 同じ外部を持つ二つの行列波 | 内部の修正の台の両側で全係数が一致。アフィン時刻の積分差の絶対値は \(6.1\times10^{-18}\) 未満。一次導関数を4次の中心差分でも取り直し、局所真空のRicci条件の最大残差は \(10^{-9}\) 未満。 |
| 物質に入る偏極 | 直交行列とスピンのユニタリ行列の規格化、全四Clifford生成元を共役作用した像を比較。左右の振動子行列を直接構成し、低い占有状態で横Dirac演算子の二乗とスピン結合を照合。元の二重交換子から求めた物質勾配への駆動も比較。二つの物質成分への移行確率を、六成分を直接伝播する計算でも検査。\(k=0\) の行は \(k\to0\) の滑らかな輸送で、零モードの光円錐ゲージではない。 |
| 記録に含み得る情報 | 各状態の最終軸をそろえた相対回転の複素固有位相から、偏極に限った最適識別能を算出。既知のユニタリ識別定理の適用であり、理想並列数は現実の物質中の記録個数を表さない。 |

## 形式化した範囲

Lean 3.51.1、mathlib3の固定版。29命題の対象は二重交換子の線形化、ゲージ方向の拘束、角スペクトルを与えるスピン合成の算術、全スピン和、フェルミオンの仕事と到達必要条件、四次エネルギー下限、前景の径と物質を合わせた確率評価、回転共分散のHilbert–Schmidt評価、光円錐生成子の規格化、凸包と物質の確率である。振動子の下限は滑らかな有限支持波動関数について、微分と実区間積分により形式化。確率評価は任意の測度上で、内外のエネルギー下限から導いた。スピン表現・Majoranaの同定、曲がった全作用の量子測度、全Gauss制約の非線形な解、実験精度はその命題の前提又は対象外である。全行列の特異点解消や、一般の落下物質が不可逆な電荷を作ることへの形式的な証明はない。
