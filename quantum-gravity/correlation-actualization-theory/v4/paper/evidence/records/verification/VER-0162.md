|---|---|---|
| 行列の射影、外部質量、ポテンシャル | 二つの半回転の積まで含む群平均で四射影の階数がすべて1。複素数値で三次の跡と交換子ノルムを直接計算 | ランク一の射影表現、局所商 |
| 一定の重力係数の対照 | 所与の非零電荷を固定し、中心と外の境界条件から周波数も解く。数値のエネルギーと \(8\pi\) 倍の無次元スカラー電荷の相対差は \(2\times10^{-7}\) 未満 | 勾配の外部エネルギーを含む。固定周波数だけの探索では自明解に落ちるため、正の電荷とエネルギーを明示的に検査 |
| 単位球面上の物質の束縛 | 平坦背景の五解のビリアル残差はエネルギー比 \(10^{-7}\) 未満。外の二点で指数減衰の係数を照合。球対称Hessianに電荷制約を加え、刻み0.12と0.08で比較 | 平坦空間の並進ゼロモードの誤差は刻みの二乗で減少。連続する全重力摂動の証明は含まない |
| 自己重力のある二つの枝 | 高密度解ではADM質量を積分と無限遠の計量で計算。変分で求めた球対称二次形式は電荷を一定に保つ差分と照合。別の希薄枝は独立なSchrödinger–Poisson境界値問題から完全な方程式に接続 | 48組までの基底で高密度解の付近に負の方向は見つからなかった。希薄枝では結合エネルギーを確認 |
| わずかな尺度結合 | 自己重力を含む質量の固定電荷微分と、物質の応力トレースを積分する二通りで自由粒子に対する応答比は 0.9992021162 と 0.9992021163。Cassini許容区間の両端を元の式に代入 | 追加の力が太陽系で長距離、普遍的かつ遮蔽なしの場合。観測データの尤度の再解析は行っていない |
| 重力での読出しと時計比較 | 薄い壁の表面応力の直接積分と部分積分が一致。有限の壁では二成分波動方程式の最小固有値の零点と空間Fourier応力を二格子で計算。周波数に対するエネルギー・電荷の差分は \(dE/dQ=\omega\) と相対 \(2\times10^{-5}\) 未満で一致。二物体の流束は中間面の積分と遠方の式を三間隔で比較 | 近似的に固定された二体、電荷交換の一次応答。自由な電磁波による読出し、放射減衰時間、通常時計の同定は対象外 |
| 一ループ静止球の演算順序 | 3組の質量で運動量積分を対数核に照合。内部行列を変形して別々に対角化し、2段階の差分による形のエネルギー曲率とスピン多項式を \(N=2,3,5,9,16\) で比較 | 二外部・二内部の磁束を持つ先頭項。丸い点の質量比はO.4を再現。O.4の有限変形の係数には今回の順序補正を用いる |
