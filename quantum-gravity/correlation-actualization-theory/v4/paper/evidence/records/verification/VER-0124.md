| 対象 | 独立に比較した量と範囲 |
|---|---|
| 荷電面の期限 | 滑らかな密度の外縁指数を4、8、16、32、64とした。面の速度を暗黙曲線の微分と近傍の二点差分で比較。指数16では最初の対、外側が時間的になる時刻、検査殻の到着はそれぞれ \(2.3312455,\ 2.6226588,\ 2.8234878\)（\(r_s/c\) 単位）。指数4と8では外側が時間的になるより中心の収縮完了が早い。単位電荷は仮定した変分拘束に対する整数結果。 |
| 相対場が担う正負の電荷 | 滑らかな二成分ハミルトニアンの二つの固有状態を八面体の頂点で求め、8枚の三角形でゲージ不変な重なりの位相を足すと電荷は −1、+1。有限速度で円を一周する記録を四つのギャップで直接時間積分し、回転座標系の解および遷移を相殺する追加項ありの場合と比較。 |
| 一様な星を吸収する作用 | 面の共動座標、横切る固有静止質量、面の局所系での入射エネルギー、圧力仕事を常微分方程式で個別に積分。\(r_s=G=1,\ M=0.5\) で静止質量0.500000、入射エネルギー0.923880、圧力仕事0.923880、最終物質エネルギー1.847759。半径ポテンシャルの二階差分からも \(R_*^2\omega_R^2=0.987437\)。相対収縮時刻が \(10^{-5}\) 遅れるだけで最初の逆時計作用の法線残差は \(3.92\times10^{-5}\)。 |
| 非一様な星の受信作用 | 独立に星の外縁から中心への光線、中心から全物質殻への面の運動を積分。質量ラベル \(2m=x^3\)、殻の収縮時刻の遅延 \(t_s(x)-t_s(0)=\delta x^2,\ \delta/r_s=0,0.03,0.10\)。信号の放出半径を基準の0.98、1、1.02倍とした。9例で最終 \(C=0.681570\)–\(0.738613\)。法線・時計の拘束残差は検査点で \(4.5\times10^{-16}\) 以下。基準の一様解では停止点が積分区間の右端に一致し、ODEのイベント配列に入らないことがある。解析値と終端値を直接比較してある。 |
| 入射と放射の圧力 | ダスト中の固定半径で加速度をラピディティの変化とダスト速度勾配から計算。流入4条件で補正後の圧力残差は \(2.3\times10^{-16}\) 以下。別に外向きヴァイディヤ時空で、正の連続光度が有限時刻に消える質量履歴を251時点で検査し、法線圧力、放射電荷、質量の最大残差は \(6.7\times10^{-16}\) 以下。別に動く面での3拘束を検査した。さらに重力方程式を入れる前の受信・放射作用そのものに滑らかな局所変分を加え、時計、面のラプス、半径の3方向で作用差分を解析的な電荷・エネルギー・圧力と独立に照合。計算で選んだ光度は放射の微視的発生則ではない。 |
| 局所場と参照 | 正負・ゼロの相対受信、三組の運動量と初期質量で、全フレーバー行列の時間発展を独立な回転基底の方程式と比較。振幅差 \(7\times10^{-12}\) 以下。有限領域の全自由場への拡張にはディラック方程式の有限伝播性を用いた。 |
| 熱分布 | 滑らかなパルスの時間刻みと紫外切断を変え、低周波の傾きから推測する温度でのフェルミ気体エネルギーとの比 23.33649、1.53211、0.44539を計算。指数ギャップに有限端を付けた例は6周波数で理想占有数との絶対差 \(2.9\times10^{-4}\) 以下。 |
| 残存物と遠方の波 | 動く面上の正規直交枠の加速度を計量から独立に求めた。正則な終端で記憶の逆数の積分が有限となる条件、固有時間だけで仕事を数える場合の違い、残存コンパクトネスで質量を落とす例を照合。遠方のスカラー波は質量重み付きモーメント \(A_0=0.01/105\) の正の入力で、\(u=4,10,40,100\) に残るエネルギーを積分して下限と比較した。 |

Leanの60命題は、電荷整数、面の速度、受信質量の積分、二つの時計作用の拘束、正の密度勾配残差、二つの枝が生じる因数分解、圧力補正と放射電荷、受信中の半径固定と放射中の半径の自由度、角速度の条件、終端での積分不等式、与えた特性方程式からの散乱の下限、リコイルの位相空間についてのものである。作用の場の変分、曲がった時空全体のディラック方程式の存在、アダマール状態の伝播、局所代数から将来無限遠への写像の全解析をLeanで証明したものではない。これらは原稿に仮定付きの物理計算または先行文献の結果として記した。
