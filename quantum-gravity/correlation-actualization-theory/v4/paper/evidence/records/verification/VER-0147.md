# VER-0147　球面の保存量、落下物質の角度差、ゼロ面積に先立つ電荷と反跳

2026-11-24。RES-0160・DER-0160・PLAN-0117。第7巻付録T.8。[導出](../derivations/DER-0160.md)・[計算](../../workspace/code/cat_spherical_receipt.py)・[数表](../../workspace/verification/cat-spherical-receipt-results.json)・[形式化](../../workspace/verification/CATSphericalReceipt.lean)・[原典](../literature/notes/cat-spherical-receipt.md)。

プロジェクト直下で Python、NumPy、SciPy を使い \(\texttt{python -B code/cat_spherical_receipt.py}\) を実行する。乱数と外部データは使わない。配布資料はZIP内で \(\texttt{python reproduce.py sample}\)。Lean 3.51.1、mathlib3 \(\texttt{65a1391a0106c9204fe45bc73a039f056558cb83}\) を使用し、同梱の再現器では \(\texttt{python reproduce.py lean CATSphericalReceipt.lean --toolchain <dir>}\) で検証する。

同じ面積式が遠方に課す条件として、有限半径の上限、積分した接方向の力の下限、および \(F_\infty>0\) での \(-2(F_\infty+1/F_\infty)\le-4\) も形式化した。最後の式に用いる \(r\partial_r F\to0\) は外部解についての仮定である。

| 対象 | 独立な検算と結果 |
|---|---|
| ダストの源と局所読み | 流線ラベルに依存する非一定の密度で質量保存と渦の式の差分残差は \(1.17\times10^{-9}\) 以下。特性格子70、140、280分割、節点の逐次遅延積分を比較。源ありの終点 \(\Psi\) の最細格子での2方式の差は \(4.25\times10^{-8}\)。解析下限と二方式での正値を確認した。単側からの散乱も別初期値で実施。 |
| 中心での波 | \(\ell=1,2,3\)、Killing運動量0,2の6条件で有理数のFrobenius漸化式と離れた半径への積分を比較。今回の半径で差は \(7\times10^{-16}\) 以下。一定張力 \(\kappa=\pm0.8\) の場合は二多重項の二次係数を調整し、三次係数の不一致 \(\pm4.16667\) を直接の波の積分と照合。 |
| ゼロ面積の計量と薄殻 | 残り固有時間の直接積分と \(r^3/3\) の比を四半径で比較し、\(r=0.0625\) で1.00000327。殻の応力を二つの外部曲率の差から生成し、解析式と六条件で比較。 |
| 量子的な横偏極 | Jacobiの加法公式で有限差を安定化。3階数・3種類の角スピンとフラックスで元の二次核と独立の放物型方程式を積分。許容誤差を100分の1にした再計算と比較。Wronskianの誤差は \(2\times10^{-10}\) 以下。有限時計での粒子数と無限区間の公式は別に記録。 |
| 二端の物質 | 受信体の保存エネルギーを点検。実スピン3、8で縮約前の全行列を組み、運動方程式・ガウス条件・長方形湯川演算子からの二準位への漏れを検算（最大 \(9\times10^{-14}\)）。三時点の二つの端の半符号数は \((0,0),(0,1),(0,0)\)。各階数・四時点のSchrödinger解を500ステップのユニタリー中点積と比較。 |
| 共通時計での反跳 | 半径幅を0.06および0.18に変え、38点と52点のGauss積分で符号識別を照合。変分Schrödinger方程式から共役運動量を求め、端付近で中心差分との差 \(1.8\times10^{-11}\) 以下。固定形状の全色回転補正の上限は \(j=2^{36},g_1^2=0.16\) で振幅0.00130。これは多体・全偏極の誤差上限ではない。 |
| 行列に備わる時計 | 球の三行列と速度の反交換子を元の有限行列上で評価し、固有値 \(aa'\) と照合した。準備時・読取り時ともこの時計が同じ値を示す時点を半径成分ごとに解き直した。三階数と大階数で符号と電荷確率を比較した。Leanでは時計の導関数 \(E-3a^4\) と折返し近傍の単調な向きを検証する。 |

Leanでは接方向の源を伴う発散式から面積式へ移る恒等式、全ての時計での保存、有限多重項の正性と負の中心勾配との矛盾、追加力の内積下限、経路微分による計量作用の停留性、張力項を射影した極限の矛盾と三次の不一致を形式化した。ダスト渦の係数・正の遅延項の下限、ゼロ面積解の半径勾配、殻のヌルエネルギー条件の境界、補償電荷・力との共分散、四色添字のノルム評価も対象に含む。形式化に渡す波の中心漸近は引用した波動方程式の定理である。行列模型の汎関数積分全体、理想光学系、連続の摂動PDE、完全な色ゲージ量子化、数値の丸め誤差をLeanで証明したという意味ではない。
