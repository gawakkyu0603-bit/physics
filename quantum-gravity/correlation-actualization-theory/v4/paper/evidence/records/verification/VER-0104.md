# VER-0104　層間の作用、有限時間の受信、二つの終端の検証

2026-11-22。[RES-0116](../results/RES-0116.md)・[DER-0116](../derivations/DER-0116.md)・[出典照合](../literature/notes/brane-flux-interface.md)。

| 計算対象 | 証拠と検証の範囲 |
|---|---|
| 巻数・電荷のしきい値 | [Lean W](../../workspace/verification/BraneFluxInterface.lean)で、平方根からの相対論的エネルギー恒等式、整数分割すべてでの最小性、奇数の正の仕事と偶数での消失を形式化。原稿の \(N\ge1\) に対する、二つの正の単位巻数への分割。ほかの励起や境界が動く場合は独立に扱う。[Python W](../../workspace/code/brane_flux_interface.py)は40通りの整数と9組の質量尺度、各91の分割を直接探索。最大絶対差 \(3.54\times10^{-14}\) 未満。 |
| 弦の頂点、偏極と物質 | 五つの独立な外部偏極について角度ごとの写像と積分したグラム行列を計算。相対符号を反転した物質からの放射を別々に構成。等長性・角度積分の誤差は \(9\times10^{-16}\) 以下。二つの物質吸収確率は独立な時間発展でも照合。指定した基底への粒子種別の部分幅であり、全超対称多重項の包摂幅を形式証明していない。 |
| 層の実在、輸送、幾何の選別 | 同じパウリ輸送をもつ物質への写像と、別々に識別できる線への写像の次元はそれぞれ1、0。入替え可能な線の組は保たれる。具体例では \(D0=3\) で静止支持物に停止仕事を渡す候補が \(r=42.34R\) で既にしきい値に届く。四運動量を保存する低エネルギーの \(D0=11\) の例でも、実際に吸収される信号の向きが結果に影響する。[数表W](../../workspace/verification/brane-flux-interface-results.json)。 |
| 無数の層、M円の相互作用 | [Lean X](../../workspace/verification/ContinuumLayerInterface.lean)で一般の二つの確率測度の反復積分をモーメントの積に変形し、収束する全調波の上界と重みの細分不変性を確認。コヒーレンスが全層に共通にずれる反例を明記。[Python X](../../workspace/code/continuum_layer_interface.py)で48、96、192点の直接二重和を連続な包絡の解析値と比較し絶対差 \(10^{-12}\) 未満。位相に依存する対相互作用でも安定帯を確認。円上の像の和から得る位相とフーリエ表示の差 \(1.43\times10^{-9}\) 未満。 |
| 絶対率、部分的な削除、受信者 | 普通のD1遷移に対する時間・強度を計算し、テンソルとKKベクトルの振幅釣合い、暗い出力、正しく消去できる割合 \(36/65\) を形式化。有限回の滑らかな位相受信と、厳密にゼロの出力をもつ材料は区別。全方位、既知の電荷参照、二つのモードのコヒーレントな吸収は条件。普通のあらゆる物質で起こる率や第11次元の存在を検証した結果ではない。 |
| 有限時間と確率 | 実際に変動するパルスを時間積分し、外部クロックの読みにFFTで変換。平均と分散を、振幅微分から得る式と比較。広い膜のAとBの0.201%、0.114%は片側分散不等式による上界。FFTで得た \(10^{-28}\) 程度の裾は浮動小数点限界のため物理的な精度として使わない。位相推定の誤差に関する計算では受信数、結合できるモード、事前の相対位相を指定した。 |
| 一般の穴での有限時間と地平面への吸収 | 球対称質量条件からの速度不等式と置換後の固有時間積分をLeanで検証。Kerrの上界に使う平方根不等式を形式化し、4つのスピン値で積分を独立に評価した。地平面の潮汐加熱は原著の主要項を使い、円軌道でのテンソルを一周積分した値と量子数の式を照合。球対称殻への放射書込み、一般のKerr内部の曲率特異性は導いていない。 |
| Bから届くホーキング放射 | 四量子の二種類の符号語について、Leanで全4消去位置、全出力ビット、全論理行列要素を整数で計算し規格化。Pythonで未知の量子状態の非対角項を含む部分トレースを独立に計算。誤差 \(1.12\times10^{-16}\) 未満。条件付き型の出現率を下から抑え、有限回数の二項分布の裾を再現。[数表X](../../workspace/verification/continuum-layer-interface-results.json)。 |

球対称な流入では放射に代えて面積変化を使った。入射データを保つ限り直交する記録の数は \(\lfloor D_f/(D_i d_L)\rfloor\) 以下である。三つの次元を6、2、144とした12記録の場合、Fourier作用の書込み率は11/12、恒等作用はゼロ。12,000本の正規化した複素Gaussian列で、静かな確率が1/4を超える割合を独立に推定した。乱数seedは116。四次元ループ重力でスピン1/2の融合を独立に数えた。大レベルの25通りの穿孔対数をCatalan数と比較。レベル2で各対が一量子ビットを持つと、対を三組加えても追加記録ができない。一般の個数に対する容量の不等式とレベル2の比をLeanで検査した。因果集合では4個と5個の標識群で126通りの4前駆元を数え、標識群内の置換を同一視すると5通りになることを確認。面積からの統計的状態数、記録の混合と必要な因果的接触時間は物理的仮定である。

Lean 3.51.1、mathlib3 `65a1391a0106c9204fe45bc73a039f056558cb83` で2ファイルの66宣言（Wが32、Xが34）が通過した。定理はファイル内で明示した仮定の下の数学を検査する。膜と層を同一の核で扱う仮定、時空の準備、放射の境界等長写像、天体における実現、新規性の優先権はLeanの主張に含めていない。

プロジェクトでは `python -B code/brane_flux_interface.py` と `python -B code/continuum_layer_interface.py` で二つの数表と図を再生成できる。配布書庫では `python reproduce.py sample` で多層の数表を退避した新しい作業場所で再現する。もう一つの計算は `python reproduce.py run brane_flux_interface.py`。二つのLeanファイルは `python reproduce.py lean <ファイル名> --toolchain <インストール先>` で検証できる。
