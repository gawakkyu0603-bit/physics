# VER-0082　相互作用する層の条件付き計算

2026-11-21。[現行の仮説と記号](../hypotheses/HYP-0004.md)・研究計画。方針を選別するための局所的な数学の検証を扱う。

**形式化。** プロジェクトの Lean 3.51.1 と mathlib3 の版 65a1391a0106c9204fe45bc73a039f056558cb83 で [InteractingHistoryLayers.lean](../../workspace/verification/InteractingHistoryLayers.lean) の16命題すべてをコンパイルし、終了コード0を確認した。省略証明・追加公理は使用していない。

| 計算 | 前提とLeanで確認した範囲 |
|---|---|
| 層の生成 | 形成・非形成の直交出力、従来の発展と追加写像の等長性を入力としたノルム保存を formation_norm で検査。四量子の二配分の自由エネルギーは four_quanta。実際の物質からの等長写像は仮定。 |
| 層間重力のエネルギー | exclusive_source、square_displacement、mutual_energy、mixed_work。共存する二つの可換応力について、複素結合の実部と虚部を分け、平衡エネルギーと応力を両方変えたときの仕事を形式化。量子振動子の変位演算子と一般の重力の拘束はこの形式化の入力側にある。 |
| 交換と局所的な確定の両立 | mode_normalization、mode_overlap、shared_and_resolved、equal_receipt。規格化、共通モードへの射影、固有モードを受信して判定する確率を検査。物質が誤りなく受容するチャネルの実装は仮定。 |
| 既に出た場の受け方と後続の物質応答 | receive_only、missed_overlap、passive_invariant で、未受信のモードを含む内積が保存される関係を検証。feedback_difference、no_retarded_path、identical_stress は、物理的な四重極の変化から出る平均力の差と二つの消失条件を扱う。一般の時空での遅延伝播や無信号定理は別途検証が必要。 |

**数値による独立な照合。** プロジェクト直下で次の計算を Python、NumPy、SciPy で実行した。[計算コード](../../workspace/code/interacting_history_layers.py)・[基準数表](../../workspace/verification/interacting-history-layers.json)。

    python -B code/interacting_history_layers.py

- 二つの物質応力を三つの重力モードに結合し、各振動子のハミルトニアンを粒子数基底で直接対角化した。二つの応力変化の混合差は解析式で −0.0049056、32準位で −0.00490560000000255。18準位との違いは \(1.3\times10^{-15}\) 未満。
- 一つの共通モード、二つの受信モード、二つの未受信モードを全て残して内積を求めた。重なり0.4で受容率を0.85と0.20にすると、層を特定する条件付き確率は0.51と0.12。未確定の場の重なりを掛け戻すとどちらも0.4になる。共通モードのみ、専有モードのみ、完全受容、受容ゼロも検査した。
- 記号の物質状態が後続の応力を本当に変える例で、混合エネルギーを座標差分して力を算出した。平均力の差は解析式で −0.04961629193、差分で −0.04961629185。数値は任意に選んだ規格化例である。落下者の運命の天体物理的な予想とは別である。

一人の局所的な有効作用、独立な層の応力、識別できる受信モードを仮定した確認である。層自体の実在、全蒸発、エネルギーの二重計上を避ける一般的生成則、時空の創発および最先取性は未確認。
