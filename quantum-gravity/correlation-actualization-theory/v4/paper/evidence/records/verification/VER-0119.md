| 検査 | 再計算と照合範囲 |
|---|---|
| 球面物質の応答 | 2種類の物質速度、4種類のラプラス周波数で対準位を4万項まで加え、残りを単調な関数の二つの積分で挟んだ。円筒の角運動量0から7について、ガンマ関数の乗数と漸化式を比較。5種類の結合で遅延列のラプラス変換と分離したパルスのエネルギーを照合した。 |
| 有限温度と種の数 | 真空で整合した平面の反射下限が \(\exp(-\omega/T)\) になることと球面の初期対励起の温度依存性を評価。有限占有の組み合わせを積とガンマ関数で比較。熱平面を四次元の実在の地平面と同一視していない。 |
| 四次元の外部 | 7組の角運動量・周波数について、\(9r_s/8\) からのスカラー動径方程式をDOP853で解いた。外側の打切り半径600と1200 \(r_s\) の間の透過率差は \(2.69\times10^{-6}\) 以下、流束保存誤差は \(3.88\times10^{-9}\) 以下。内側の自由端に対する透過率で、蒸発する面の時間依存放射率ではない。 |
| 運動する受信面 | 入射エネルギーと交差半径を変えた3例で先着電荷と物体の時計を別々に積分し、面の因果的な面積上限を計算。放出と入射のヌル時刻の微分、および対数微分を独立な時刻差で照合した。表面を停止させる3例と、指定した静的最小距離の対数見積もりを収録。 |
| 電荷の先着による解放 | 入口から留め具に信号が届く時間を含め、指定した二つの入出時刻に合う長さと質量・張力比を解いた。13個の反射点で受信後の軌道、光線の交差と張力の仕事を照合。一様入射に対する非線形の運動量方程式と放出の時計を独立に積分し、6種類の負荷で閉形式と比較。最後の放出が基準時刻に届く入射量を求根した。 |
| ホーキング放射との比較 | 無負荷の共形動径場について、放射のシュワルツ微分に加え、終端を二種類に変えた6対の有限な時刻差で電流の二点関数を直接評価。有限時間の出力状態全体が熱平衡であることや、自重で蒸発したことの証明とはしない。 |
| 量子的な反跳 | エネルギーと正のヌル運動量の逆写像を9例、対数測度上のヤコビ行列を中心差分で独立検査。端の初期運動量を \([3,5]\) に一様とし、二つの有限幅エネルギー帯を変えた3例で、反跳分布の平方根の重なりを直接積分した。3例目ではゼロ。 |
| 最後の二光子の脱出 | 8組の放出位置・境界半径について、親粒子の静止系の10万方向と脱出円錐の閉形式を照合。外向き親粒子の固有寿命を6条件で積分し、光子球で区間を分けた。待ち時間の積分打切り誤差は、全確率の上限を用いて4.25×10⁻¹⁸以下。光子のエネルギーが十分高い場合の直接脱出を扱う。 |
| 境界へ戻った電磁波 | 固定導体の二偏極を4次元マクスウェル方程式から還元し、双極子、四重極、3周波数で定在波の強度を数値積分。外端750と1500 Schwarzschild半径の差は5.0×10⁻⁷未満。角運動量障壁の二つの転回点と指数の積分を独立に計算。既知の半直線スペクトル定理に適用した条件を導出に記載した。 |
| Lean 3.51.1で通過した54件の命題 | 球面の既知のスペクトルとくりこみ条件を入力とし、接触項、反射係数、温度下限、遅延窓、固有時計、赤方偏移を検証。解放時刻の微分と分数線形写像、張力の仕事、入射を含む保存式、積分因子による正の負荷の比較、反跳の逆写像・非交差支持の部分トレース、時計精度との制約を形式化。曲がった時空の相互作用QFT、フェルミオンを積分する経路積分、量子重力の成立そのものを形式化したとは主張しない。 |
