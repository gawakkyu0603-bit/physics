# VER-0084　潮汐で生まれる連続な層と分離時点の検証

2026-11-21。RES-0094、DER-0094、第4論文付録M。著者指定は Yohtaro Soga。手法、計算、形式化、原典照合、英文草稿は Codex による。

## 再現

数値計算はリポジトリのルートから python -B code/bound_graviton_breakup.py で実行する。Python、NumPy、SciPy、Matplotlibを用いる。乱数は使わない。[コード](../../workspace/code/bound_graviton_breakup.py)・[数表](../../workspace/verification/bound-graviton-breakup-results.json)・図。配布用の reproduction.zip では python reproduce.py check、python reproduce.py sample、python reproduce.py lean BoundGravitonBreakup.lean が対応する。

Lean 3.51.1とリポジトリ指定のmathlib3で[形式証明](../../workspace/verification/BoundGravitonBreakup.lean)の70命題が終了コード0。公理の追加・sorry・admitはない。以下の対応は物理的な近似と数学的検証を切り分ける。

| 対象 | 独立な確認 | 範囲 |
|---|---|---|
| 散乱前の四重極の係数と角テンソル | 運動量射影の差分と、位置表示の正則化した角積分を別々に計算した。差分誤差は約 \(6.8\times10^{-8}\) 以下。Leanは商の二次係数、射影の反射と跡内積を検証。 | 初期波動関数の裾と三点規格化は原著の入力。 |
| 中心の散乱補正 | 半径を半減してベッセル積分を取り直した。外側反射壁による補正のべきは軌道角運動量0、2、4で1.999、3.998、5.999。 | この壁はBFSSの非可換な中心部を解いたものではない。 |
| エネルギーと円方向 | 位相空間を積分し、ガウス歪みの入射での分離確率と投入エネルギーを数値検算。 | 線形背景、弱結合の応答、\(kR\gg1\)。光面運動量の総量は固定。 |
| ボルン重みと発生頻度 | 第一ジャンプの確率密度を積分し、活性な層の重み0.23、0.51と書込まれない重み0.26を回復。連続ガウス作用では全層を平均して元の重みに戻る。数値の最大誤差は \(5\times10^{-17}\) 以下。 | Born則は任意の時刻の条件なし状態について成立。特定の時刻の発生に条件付ける場合は、重力応答で重み付けする。 |
| 層自身の連続的な分離 | ガウス積分を数値積分し、全二点間の重なりと解析式の最大差は \(2.4\times10^{-15}\) 以下。Leanはガウス測度の平行移動、規格化、二つの曝露の合成、減衰が始まる条件を積分として検証。 | 可換な応答部門。関数積分の変数は選択された物理的な層状態をパラメータ化する。 |
| 位置選択に要る仕事 | 周期的な二調波応答について、対の反跳エネルギーを波数ごとに足した値と、応答勾配の二乗を全周積分した値を独立に照合。Leanは二重交換子、円弧平均の仕事の下限、逆向きの運動量とエネルギーの交換を検証。 | 既知の弱場の行列作用と物質参照での有効記述。全宇宙の局所Ward恒等式は未導出。 |
| 履歴が二つの位置を含む例 | 既知の行列エイコナル位相の周期像和を計算。中央の参照は鏡映した二点を区別できず、ずらした参照はそれらを区別する。\(b=3,v=0.6,y=1,s=1.5\) の無次元例で、円を開いたときの曝露当たり分離指数は \(2.24745316\times10^{-8}\)。Leanは二つの異なる物質参照の距離が位置を定めることを検証。 | 直線運動、識別できる物質源、弱い位相。数値は物理定数の予測ではない。 |
| 無数の相互作用し得る層とM理論の散乱 | 連続応答ベクトルの二重積分恒等式を、任意の確率測度と実Hilbert空間についてLeanで検証。複素応答は実Hilbert空間として適用可能。256等幅区間の \(M\sum p_j^2\) は1.63169、解析極限は700/429。| 全回転表現44と超スピン零を区別。二値の角領域を書いた場合の超スピン二の増加を球面積分で再計算。 |
| 一人だけが知る条件・層の合流 | フェルミオンの二モード回転を部分跡し、8モードの全256通りを列挙。単一ブロックでの最適識別は3807/4096。非負の同時占有、無限個の交換対称な観測者、上向き・下向き遷移の定常値の制約を形式化。 | 指定した準備の同一因果領域。一人だけを根本的に名指す法則の実証ではない。 |

論文の中で用いるベッセル積分、フェルミオン表現、超対称Ward恒等式は解析上の入力であり、LeanではBFSSの連続状態スペクトルや量子重力の作用の一意性は証明していない。外部原著の適用箇所と新規性の範囲は[文献照合](../literature/notes/bound-graviton-breakup.md)に記した。最終理論に対する実験予想は未確定である。
