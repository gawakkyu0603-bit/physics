# VER-0102　地平面での状態選択と、放射による回収

| 主張 | 検証と適用範囲 |
|---|---|
| 通常の吸収の一回計数とボルン分岐 | Leanの非可換環の恒等式で、等長写像・直交分解を仮定して分岐の正作用素の和を求めた。重力吸収の発生率を重複計数しない。幾何を選ぶ対応は追加仮説。 |
| 異なる受信履歴、到着回数と層の厚み | 物質と場の二つのベル状態を用い、各信号の密度行列が等しい三状態に交換射影を作用。独立経路と共通の回転を比較。ポアソン確率を80項まで直接和算し、連続な平均回数の解析式と比較した。Leanでは対称射影の入れ子に必要な演算子恒等式、有限和と指数母関数の無限和、縮退極限の時間微分を検査。零・一受信で地平面に移る候補では、99%しきい値を数値求根し、完全混合時の最大値を独立な最適化と微分式で照合した。 |
| 地平面の因果・有限時間 | 因果関係の推移律から遅い信号の禁止を形式化。局所的な捕捉面について二つの蒸発率で逐次数値積分を行い、光の離脱を線形化、固有時間を解析積分と比較。外部共鳴器への入射と反射を時刻で積分し、放出・残留を合わせて1と照合した。 |
| 熱的な四次元放射の情報制約 | 光子と重力子の係数を有理数で再計算し、両者を合わせた粗視化エントロピー比1.48472をPageの公表値1.4847と照合。Leanでは詳細釣合いからの放射率、蒸発時計の原始関数、情報量の不等式を仮定した上界と係数の算術を検査した。量子情報のデータ処理不等式、黒体の最大エントロピー性、Schwarzschildの吸収スペクトルは既知結果として用いる。 |
| 成分弦の冷却 | 三角形に並ぶ占有数から全消滅作用素を作り、零空間と時間積分を特異値分解またはSylvester方程式で求めた。2・3・4本の弦で母関数から導く終端分布と照合。三本で120度をなす記録は有理数演算で核射影と各段のSylvester方程式を検査した。指数の積分、二振動子の梯子、次数ごとの次元差の代数をLeanで検査した。 |
| 偏極と量子状態の回収 | 二つの偏極と基準系の密度行列の部分転置でネガティビティを計算。境界確率が1と1/4のフィルターは0.4に達する。Leanで選択率の偏りと回収もつれの上界を証明した。使用した純粋状態のSchmidt分解と局所操作による単調性は既知。四周波数の符号は2×2の全入力行列単位について全ての一周波数部分トレースを直接検査した。 |
| 巻数・有限時間・別の発生仮説 | 共通周波数と最大公約数の同値を全巻数についてLeanで証明。中性帯域を独立に和算した。暗状態を持つ有限数の対を疎行列の指数で発展させ、初期放出率、確率・エネルギー保存、記録が薄れる場合や離調する場合を比較した。 |
