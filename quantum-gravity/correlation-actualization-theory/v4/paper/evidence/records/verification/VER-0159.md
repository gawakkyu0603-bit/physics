# VER-0159　半径、安定性、物質のスカラー電荷

2026-11-24。対象は [RES-0172](../results/RES-0172.md) と [DER-0172](../derivations/DER-0172.md)。[計算コード](../../workspace/code/cat_radius_matter.py)・[数表と逆ヘッセ行列の全成分](../../workspace/verification/cat-radius-matter-results.json)・[Lean](../../workspace/verification/CATRadiusMatter.lean)。

| 対象 | 方法と確認範囲 |
|---|---|
| 行列から求めた質量と力 | 階数2、3、5、8で \(SU(2)\) 生成子と二種類の随伴二重交換子を直接作り、非零スペクトルおよび一ループ係数の跡を軸変形の解析式と照合。共通サイズと測度因子を独立に変えて \(G_Nm_\ell^2\) を検算。最適サイズで軸方向のエネルギーを差分すると、全階数で負になった。固定三電荷の三半径ヘッセ行列は独立差分で \(6,6,12\)。回転中のGauss制約と横方向の全スペクトルも直接照合した。 |
| 調和零モード、対称性 | 素の三形式から対称行列を再構成。49代表×175短法線を試し、許された81組すべてで法線を含む正規直交枠の非対角ブロックが消え、接ブロックの最小特異値と法線成分が非零であった。各法線で固定点64個を写像して16個ずつの4群を確認。例に使うフラックスに384個の原点を保つ格子等長変換を作用させ、8個が両三形式を保存することを確認した。 |
| 安定性 | 単一巻きの幾何と指数関数の微分で錐全域を調べた。スカラー曲率の跡不等式は一般に形式検証し、Cayley座標の行列式の独立な多項式補間で非対角複素方向も照合。F項の停留点での平均質量公式は原著の入力。 |
| 五項の力とワープ | 質量固有方向に実際の物質電荷を射影し、二つの二乗和、軽モードの式を比較。局在物質では三段階の赤方偏移で静止質量の対数差分と解析式を照合。開弦ではワープの異なる四区間を足して検算。巻いたD3の質量は一次結合が消える不均一例でも二階微分が負。 |
| 重い場の伝播 | 積分三形式と正則体積形式から元の超ポテンシャルを直接評価した。10座標それぞれと全混合方向で四次まで正確な五点式と偏極恒等式によってヘッセ行列を求め、Gaussian整数の分子行列 \(N\) が \(HN=4I\) を厳密に満たすことを検査。分子・分母を数表に収録した。 |
| 二次の係数判定 | 四場の六項例で \(W=\partial W=0\)、対数座標ヘッセ行列の行列式128、正準特異値の比 \(2,2,4,4\) を確認。複素位相を含む正方点外の例で停留値と行列判定を独立に評価し、一係数を変えると両者が同時にゼロから外れた。 \(\tau=5\) で二次係数を \(10^{-5}\) ずらし、場を再度停留点に移した後のgravitino質量は一次式と相対 \(5\times10^{-5}\) 以内で一致。 |
| 観測 | Cassiniの時間遅延、Planck 2018の基準密度、Leeほかの実験距離を原著と照合した。有限到達距離の尤度再解析やハッブル定数の再推定は行っていない。 |
| 四次元に広がる回転状態 | 三つの半径・位相とそれぞれの速度を残した12成分の時間発展行列を、成長帯の内外と極大を含む五つの波数で対角化。二つの形と共通半径について全12固有値を分散式と比較。有限波数の成長、上限 \(m_1/4\) とその達成点をLeanでも検査。 |

Lean 3.51.1の40命題は、単一指数の停留条件と自由方向、跡の不等式、スカラー質量の上限、ワープした静止質量の微分、六項判別式、複素双対空間を使う二次のMinkowski条件の同値性、重い場の消去、誘導重力と物質質量の比、磁気量子数の二乗・四乗和、静止球の鞍点の符号、回転する三半径のヘッセ行列、四次元の成長帯と最大成長率などを扱う。零モードを数えるDirac演算子、IKKTの一ループ有効作用、PPN公式は原著を用い、有限の行列と物理単位はPythonで検算した。弦の全経路積分、実際の原子のスカラー電荷、非摂動CATの真空は形式証明の対象に含まれない。
