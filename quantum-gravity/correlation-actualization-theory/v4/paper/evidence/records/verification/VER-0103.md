# VER-0103　物質の潮汐記録・地平面横断・外部での量子放出の照合

2026-11-22。対象は第2論文付録V.6–V.11・[RES-0115](../results/RES-0115.md)。[数値計算](../../workspace/code/tidal_receipts.py)・[数表](../../workspace/verification/tidal-receipts-results.json)・[Lean](../../workspace/verification/TidalReceipts.lean)・[照合した原著](../literature/notes/tidal-receipts.md)。

| 主張 | 検査と判定範囲 |
|---|---|
| 同一軌道からAとBへの潮汐 | 修正Bessel関数による解析表式を、無次元周波数0.3、1、3で時間領域の振動積分と比較。テンソル成分の絶対差は \(4.5\times10^{-14}\) 以下。軌道の全放射係数を四重極の三次導関数の二乗から積分し \(37\pi/15\) と照合。物質の仕事・反跳の符号、慣性・周波数・線幅の規格化はLeanに含む。 |
| 軌道の向きに関する実際の情報 | 反射した二軌道で各偏極のポアソン強度が交換する。同じ占有数差を持つ全事象の尤度比は共通である。Leanで二つの重みの積、無限和、事後オッズを検査。Bの有限の数値例を独立なSkellam確率計算で比較し、全判定の誤り0.448059を得た。この二択は物質・場の全状態の識別とは異なる。 |
| 熱揺らぎによる偽陽性と記録の消失 | 有限の占有数基底で変位を行列指数で実装し、熱的な対の位相平均による三個の中央確率の和・平均・分散と照合。損失を受けた対の中央確率は特性関数の独立な積分と一致。正準モードの角運動量と流体の剛体回転は混同しない。 |
| 通過後の重力波と共鳴 | 軌道の放射と誘起四重極を同じ遅延時刻で積分した。開始時刻を \(-160t_b\) から \(-240t_b\) にすると初期積分終端の無次元振幅差は \(4.0\times10^{-7}\) 未満。後半は残った自由振動を時間積分。1%離調で追加振幅を全時刻で3.2%未満に抑える計算はこの自由振動近似での上界。長期間完全に共鳴する天体の実在は仮定していない。 |
| 落下中の変形・熱帯・受信の因果期限 | Schwarzschild自由落下の変形を正値の積分と独立な正弦積分で4周波数にわたり照合。変形1・3・10%の根を数値計算。Leanでは動径潮汐の置換、積分核の順序と可積分性を仮定した積分不等式、赤方偏移によるエネルギーの代数を検査。光を往復する範囲は5個の放出半径で解いた。 |
| 真空・熱放出による参照系とのもつれ | 真空の二経路の確率和、二つの射出幅を使う場合の分岐確率を検査。熱減衰の判定は既知のGaussian定理を用いる。有限スクイーズの部分転置後の固有値を12通りの透過・雑音配置で独立に算出。Leanで行列式の符号、\(w>e^{-y}\) への変形、共通の透過因子の消去を検査。有限入力の完全回収を証明する基準には使っていない。 |
| 層間の反跳、行列模型、離散時空 | 二層の共有反跳を有理数で直接評価し、Leanで連結エネルギーと関係角の積分を検査。逆べきポテンシャルのFourier強度比は直接積分とも照合。物質時計の細分では同じ端点電荷を持つ二経路が途中では異なることを形式化。Poisson散布の二乗平均誤差の積分係数を独立に積分。有限管の4000回の乱数実現（seed 115）の分散0.3433は期待値0.3313から約3.6%の差。等間隔の細分では二偏極とも刻み0.25で振幅の絶対差 \(1.6\times10^{-8}\) 未満。 |
| 球対称落下と平衡からずれた物質 | 動径速度を、正値積分および元の振動積分の有限差分で独立に照合。二つの穴サイズで記録・重なりを計算した。捕獲面の正規化は三つの幅で1との差が \(3\times10^{-15}\) 未満。球対称真空、軽い物質殻、当初の冷たい準備、外部受信器の平衡という仮定を明示。 |
| 厚い層の相互作用と落下 | 三つの結合・離調で散乱行列のユニタリー性を直接確認（誤差 \(4.45\times10^{-16}\) 以下）。周波数幅の影響は二つの波束で数値積分。連続な相対反跳では4標準偏差、離散熱状態は1対・6対で三つの半幅比を検算。幅が同じで相関の違う二状態も直接構成。Leanでは正の相対エネルギー、確率和、幅の不均衡、同値電荷が落下に残る下界、LQGの残差・KKのスケーリングを検査。さらに落下側のしきい値を上げる作用で、奇数の総電荷では二層の差が消えないこと、開いた経路の通過率、閉じた経路のエネルギー条件を形式化。総数100と101で全二項分布の和をそれぞれ計算した。 |
| 推測した量子重力作用 | 行列・スピンフォーム・因果区間の挿入は候補として記載。新しいBFSS理論の全超対称性、弦場の量子マスター方程式、離散重力の一般連続極限は未検証。ノイズのある単一放射路の検査も、全蒸発の回収の証明には使わない。 |

**再現手順と根拠の範囲。** プロジェクト直下でPython 3.14.7、NumPy 2.4.2、SciPy 1.17.1、Matplotlib 3.10.8を用いた。数表・図は `python -B code/tidal_receipts.py` で再生成する。配布用ZIPでは `python reproduce.py sample`、同梱の手順でLean環境を用意して `python reproduce.py lean TidalReceipts.lean` を使う。Lean 3.51.1、mathlib3の版65a1391a0106c9204fe45bc73a039f056558cb83。形式化の対象はファイルに明記した76命題である。Bessel変換、既知の重力・流体作用、スクイーズ変換とGaussianチャネル定理、漸近展開、全量子重力の存在をこれらの命題で証明したとはしていない。数値積分の照合は独立な計算法同士の検査で、厳密な区間包絡ではない。
