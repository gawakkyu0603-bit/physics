## 独立に照合した対象

| 対象 | 検算と結果 |
|---|---|
| シュワルツシルトの横方向潮汐 | 3種類の半径比、6種類の固有振動数で、ベッセル関数または零周波数のべき解から得た伝達行列とDOP853積分を比較。最大成分差は1.15×10⁻⁹。正準行列式も確認した。 |
| 有限質量の実際の受信端 | 二体が反跳する24条件について、端点の運動量変化と力積の別積分が最大1.39×10⁻¹⁶で一致。正の線のインピーダンス、入射の有無を変えた18条件では、同じ入射に対する出射変化と遅延フィルタの差が最大4.39×10⁻¹⁶。 |
| 四次元の灰色体透過 | 実際のシュワルツシルト動径方程式で各モードの透過・反射の流束和を検査。積分次数4から6、角運動量切断4から5、遠方展開を変えたときの積分値の最大相対差は2.09×10⁻⁵。単一エネルギーの表は別に角運動量7までを計算。高次波を厳密に全て足した理論誤差ではない。光子・重力子の全出力をPageの原著と照合した。 |
| 四体の形状 | 6次元分の多項式を有理数で直交化。不変質量による二変数積分を別座標で数値計算し、0次から4次の規格化モーメントの最大差は6.61×10⁻¹⁴。読み出す質量を二分する効果演算子の固有値と回復忠実度を算出。 |
| 相対方位角の四運動量表示 | 正のエネルギーで全運動量を保存する三種類の運動学、各64方位角、直交する6振幅を使用。全エネルギーと三運動量の最大残差2.23×10⁻¹⁶、固定エネルギーでの内積最大誤差4.53×10⁻¹⁴。ローレンツブースト、同種光子交換、局所多項式と余弦表示の最大差2.24×10⁻¹²。 |
| 偏極の局所頂点 | 四光子二配置、六光子一配置で実際の横偏極と運動量から振幅を作成。運動量を完全に固定した内積と単位行列の差は6.67×10⁻¹⁶以下。一つのヘリシティを記録した効果の差も2.78×10⁻¹⁶以下。二つのヘリシティ一致の確率を組合せ式と独立に比較。 |
| 偏極に働く実際のソフト重力 | 十二光子の二符号語に対して、恒等と各光子の三つのパウリ演算子から得た1369積を全数検査。二つの対角の差は8.89×10⁻¹⁶以下、論理交差項はゼロ。さらに正エネルギー十二体の点で、二つの横波重力偏極のローレンツ生成子を運動量と光子偏極の両方に作用させ、頂点の中心差分を独立評価した。硬い振幅とソフト振幅のGram行列の規格化残差は1.48×10⁻¹²、質量殻・横条件の残差は1.74×10⁻¹⁷。 | 
| 終端確率と半古典スペクトル | 質量倍半減の例では無終端確率0.4686351、有限積を打ち切った対数の残差上限2.06×10⁻³⁴。正のラプラス重みについて熱分布の恒等式を4個のエネルギーで数値積分。灰色体関数との相殺を調べるこの試験は、物理的な動径透過の検証とは別である。 |

## 形式化と物理的な適用条件

Lean 3.51.1で53命題が通過した。形式化の対象は、力積の符号と積分、角度の上限、縮約質量と一様ノルムの不等式、受信線の変分後の特性流・遅延・積分因子、反跳エントロピー、射影の対角和の上限、四体のヤコビアンとベータ積分の階乗値、角調和の積分直交、四重極からの角の復元、任意の有限個の複素偏極振幅の絶対値と互いに素な語の内積、既知の一光子偏極消去後の複素Gram行列、真空待ち時間と有限積の下限である。十二光子の二体密度と重み分離、任意の複素一光子因子の積の運動量微分、放出する足の重ね合わせに対する誤差積の圧縮も形式化した。ラプラス重みは正の除数の相殺を形式化し、和と積分の交換は非負関数に対するトネリの定理を用いた。

曲率の二次展開、4次元Maxwellの運動方程式、多体位相空間と標準の誤り訂正定理は引用した既存理論の入力である。連続体のブラックホール全体や、任意の自然物質が拘束を獲得することをLeanで証明したという扱いはしない。上の数表は局所頂点と伝送路の有効作用に対する照合であり、動的な外部時空を通る最終放射の全散乱行列は未計算である。
