# VER-0106　人体質量と可視粒子の重力応答の検証

2026-11-22。[日本語の導出](../derivations/DER-0118.md)・[結果](../results/RES-0118.md)・英文原稿・[原典](../literature/notes/visible-body-flux.md)・[数表](../../workspace/verification/visible-body-flux-results.json)。

| 計算 | 検証方法と適用範囲 |
|---|---|
| 受動熱光の二領域 | [Python](../../workspace/code/visible_body_flux.py)で一つの熱入力を二方向に分ける計数を占有数ごとに足し、行列式と比較。絶対差は約1.1×10⁻¹⁶。エネルギー差分布を離散フーリエ変換で復元し、特性関数の時間積分と4種類の接触時間で照合した。 |
| 連続時計と有限時計 | 三角重みの積分とモードごとの帰還率の合計は絶対差3×10⁻¹³未満。16、64、256状態でも全遅延対の直接和と電荷分布のフーリエ振幅を比べて5×10⁻¹³未満。局所電荷が共通なら幅があっても相対位相はゼロ。 |
| 光線、物質と時間 | 3、10、100万太陽質量の穴と3種類の放射体で、部分帯域の到着数、受信に必要な時刻、局所光円錐を算出。Kerr軸上の全スピンで使う解析的不等式と数値係数を記録した。球対称境界での潮汐仕事を積分式と比較した。 |
| 冷たい前端 | 重心の自由拡散、時間幅の上下限、受信面の局所仕事を確定できる場合の電荷を用いた。一つのGaussian波束の純度を誤差関数による積分と上界で検査。有限のパルスの裾と局所中継の時間を含む。 |
| 円上の重力応答 | 5種類の位相キックでフーリエ変換をBessel係数と比較した。最大の絶対誤差1.38×10⁻¹⁵未満。全確率と二次モーメントを検査。4種類の正のKKエネルギーと接触強度について、二体の総運動量ゼロの三重対角ハミルトニアンを独立に対角化し、出力の誤差上限と比較した。角度積分は修正Bessel関数で一変数に減らして数値積分とも照合した。帯域内の角周波数誤差を許す条件も記載した。 |
| 固定正運動量 | 2、4、9、16、32個の重みのある固有モードについて、開いた鎖を直接対角化した時間発展と解析的な余弦ノードの和を比較。振幅の誤差は2.54×10⁻¹⁵未満。有限鎖の最小間隔、128モードの有限時間での下限・上限、微小なエネルギー分裂への許容度を計算した。 |

[VisibleBodyFlux.lean](../../workspace/verification/VisibleBodyFlux.lean)の35宣言が通過した。線形集束からの電荷収支、定常ブースト位相、熱計数行列式、三角関数・対数・積分による包絡、有限時計対の分解、正弦の差と対数積分の上界、円の総運動量、波束の不確定性、スピンに依存する因子の消去、局所での電荷の一致を検査した。固定正運動量のエネルギー相殺、正弦固有関数の局所方程式、全モード対の和に対する上下界、1%に必要なモード数を原稿と同じ仮定で形式化した。四次元重力の微視的実現、連続な場のスペクトル、非ユニタリーな選択の存在は形式化された定理に含まれない。熱光の平均数を、ある個別の落下で実測される個数と解釈しない。

Lean 3.51.1、mathlib3 `65a1391a0106c9204fe45bc73a039f056558cb83` を利用。プロジェクトでは `python -B code/visible_body_flux.py` で数表と図を再生成する。第2論文の再現書庫を展開し `python reproduce.py sample` を実行すると、保存済みの数表を別の新しい作業場所で再計算して数値を照合する。形式検証は `python reproduce.py lean VisibleBodyFlux.lean --toolchain <Leanとmathlibを含む場所>`。
