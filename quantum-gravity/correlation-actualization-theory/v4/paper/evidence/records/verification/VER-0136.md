# VER-0136　旧CAT稿を七巻の研究データベースに移した記録

2026-11-23。関連 DEC-0135、RES-0148、VER-0135。著者 Yohtaro Soga。七巻の本文への案内・[巻別、式別、文献別の対応](../../workspace/verification/cat-database-coverage.json)・保存した旧稿。

## 何を保存したか

統合元のCAT.texのSHA-256は `3e5ab3154458c63b490c78632beaedf9efd6452c3281fe93ed23dcd2ff513005`。要旨と全10節の本文、寄与の開示を対象に、空行を除く179行の所属を一つずつ割り当てた。別巻の式には固定番号C1〜C13と巻番号を与えた。49書誌項目は各巻で既存の同一文献のキーを再利用し、内部の技術資料への一件を第4巻又は同巻付録Sへの参照に置き換えた。第5巻では十一の列挙項目と九つの測定表の両方を保持した。原TeX、PDF、配布時のソースと旧案内の同一バイト列は、移動前の履歴ZIPで復元できる。

## 検証の再現

プロジェクト直下で次を実行する。

~~~text
python -B tools/integrate_cat_database.py
python -B verification/verify_paper_series.py layout
python -B verification/verify_paper_series.py samples
~~~

最初のコマンドは旧稿の各行の所属、各式の巻をまたぐ参照、書誌の被覆、新しい各巻の本文との一致を検査する。通常の検証には書込みオプションは不要。第2コマンドは配布アーカイブからの組版と編集用ソースのバイト列、PDFの見出し・旧参照・文献・フォント・各頁の配置、CAT記録の開始頁を照合する。第3コマンドは各巻の再現用ZIPのマニフェスト、代表数表の再計算、各巻の代表Leanファイルを検証する。版を更新する場合は、該当する版の組版結果を用いる。

七冊のPDFにはそれぞれ当該巻のCAT本文が入り、再現用ZIPにもその編集用ソース、照合用の旧CAT.tex、全巻の対応データ、主題に応じた計算・Lean・参照数表を収めた。本文の版を保ったまま付け替えたPDF内の数式リンクについては、数学の入力、プログラム、Leanファイル、基準数表が検証時と同一であることをファイル別SHA-256で比較し、配布版自体の全ファイルの整合性も検査した。組版検証記録・再現検証記録。

この照合の対象は研究資料の統合と、同梱した既存計算の再現である。一般崩壊での厳密な経路閉鎖、量子重力下での全放射の回復、全ての四次元時空の導出は引き続き研究課題として管理する。
