# 行列接触と重力による吸収の検証

VER-0090・2026-11-22・RES-0102／DER-0102。第4論文付録N.25–N.29、160–169頁。数値正本は [matrix_contact_echo.py](../../workspace/code/matrix_contact_echo.py) と [結果表](../../workspace/verification/matrix-layer-work-results.json) の `matrix_contact`。形式化は [MatrixLayerWork.lean](../../workspace/verification/MatrixLayerWork.lean)。[仮定と先行例](../literature/notes/matrix-contact-echo.md)。

| 確認した箇所 | 方法と数値 |
|---|---|
| 傾いた二膜の最低励起 | 二つの調和振動子の各基底を8、14、22で切り、元の行列ラプラシアンを直接対角化。主角 \(0.86,1.1\) で、22での固有値 1.66099474098、位置差の分散 0.57503511999、共役中心の分散 0.43475605456、純度 0.82777695677。解析解との差は \(1.1\times10^{-14}\) 以下。基底端の偽の最低固有値を避けるため、一体エネルギーは射影前に二乗した。 |
| 接触の四次応答 | 位置差のGaussian積分と特性関数による式を四波数で比較。\(k\sigma=1\) の応答0.53190948329。スピンを含む固有時間積分と \(d^{-3}\) 遠方近似との比は \(d=8\) で1.00000000232。 |
| 二つの四次元波と物質のエコー | シフトした両端のGaussianの直接積分で鏡映時 \(4\sqrt\pi\)、相殺時 \(4.1\times10^{-32}\) 以下。二つの独立な古典モード方程式を積分し、四振幅でパートナー関係と行列式1の誤差は \(4\times10^{-14}\) 以下。二度のパルス後の \(\beta\) と幾何分布の復帰率を別計算。対称な対励起の確率はRicci平坦な対照波で0.04148760779。 |
| 書込みと仕事 | 連続時間の共分散方程式と、独立に積分した \(\int\sum_i\dot K_i\langle x_i^2\rangle/2\) の差が \(10^{-11}\) 未満。小振幅で二作用の損失の次数4.00130、6.00100。真空復帰率の一次補正は純粋な無監視軌道のエネルギー分散を用いた。 |
| 重力子を含む全エネルギーと連続極限 | 四離調でスペクトル射影とPauli成分を比較し、4成分の密度行列生成子を直接指数化して変換確率を照合。四運動量の反跳は別計算。連続バンドで数値積分と正弦・余弦積分の解析式が \(2\times10^{-14}\) 以内で一致。\(T=256\) の二乗ノルム0.02410897618。 |
| 散乱生成物と受け手の状態 | 二チャンネルの複素散乱行列、非選択の生成物測定、逆散乱を行列積で計算。線幅比1で線中心の残差0、半変換点で1/2。幅比0.1では中心が最大で0.44259271908。二つの非可換な物質状態について、受信後の密度行列から求めた分散が層内と層間の和に一致。 |

局所の連続接合を時間発展させると、線幅0.7と1.3の例で変換確率0.6825000000000、二種類の条件付き平均到着時刻は全線幅を掛けて5と25/3になる。第二の接合を入れた受信密度の零点で数値残差は \(1.7\times10^{-26}\) 未満。独立に散乱位相の微分を周波数積分して同じ遅延を得た。物質時計の励起確率の直接数値積分は0.5625と0.4583333333333333。

| 波の関係と復帰 | `mx_mirror` は埋込みの位相差の被積分関数。 `mx_partner` と `mx_partner_back` は微分可能関数の実際の微分から、二つのモードの一階系が相互に移ることを検証。 `mx_asymptotic_sign` は平坦端の複素波。 `mx_purity_of_pairs` は無限和を取り、`mx_echo_work` は鈍った復帰で受け手に残る仕事。 `mx_monitor_work` は共分散方程式からの仕事の相殺。 |
| 吸収と連続スペクトル | `mx_recoil`、`mx_pointer`、`mx_doublet_fit_unique`、`mx_detuned_rate` は反跳、エネルギー保存の成分条件、最近接射影の一意性と率。 `mx_diagonal_null` はLebesgue積測度の対角が零であることを実証。 `mx_sinc_bounds`、`mx_kernel_envelope`、`mx_continuum_integral` は二乗可積分核から得た非負重みについて、実際のsinc因子を含む積分が任意の正の時間列 \(T_n\to\infty\) で零になることを形式化した。零測度の対角ではsincの代表値を変更できる。 |
| 生成物と二人の不確実性 | `mx_two_pass`、`mx_width_window`、`mx_reread` は逆散乱残差・線幅・同じ出来事の再読。 `mx_private_silence`、`mx_private_loss`、`mx_total_variance`、`mx_radial_redshift` は無受信時の残存分散と単調性、量子混合したときの二次モーメント、落下による周波数移動の代数。 |

局所受信について `mx_flux_bilinear` は独立な二解に対する入出力流束の恒等式。`mx_pulse_dynamics` と `mx_filter_dynamics` は時間依存振幅が二つの微分方程式を満たすことを検証。`mx_arrival_moments` は半直線の実際のガンマ積分から二つの規格化と平均を算出する。`mx_clock_intertwine` と `mx_clock_spectra` は同時エネルギーの保存の成分条件と、規格化した特性関数による二つの終状態確率を確認する。

物理入力には、標準のBFSS二次スペクトル、IKKT背景のMoyal積、局所Fermi座標、量子振動子の正準量子化、連続散乱のスペクトル表示・孤立共鳴近似を用いた。これらの理論の構成、非有界量子場の全発展、一般相対論とノイズの局所Ward恒等式まではLeanの主張に含めていない。小振幅指数の非零係数は指定した滑らかなパルスで数値検証した。
