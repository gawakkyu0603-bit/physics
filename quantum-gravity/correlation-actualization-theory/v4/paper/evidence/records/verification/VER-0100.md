# VER-0100　落下物質から放射への量子移送

| 計算 | 照合 |
|---|---|
| 受信アドレス | 三体のグラム行列の最小固有値、対称な中央タグの上限を実内積から導いたLean命題、早期の放出係数の最大値と1万分割の探索。二体の反跳だけに同じタグを重ねた場合も比較。 |
| 物質準位 | 水素型動径積分、Legendre積分による角運動量和。\(4d\)の四つ、\(4f\)の二つの四重極崩壊を含む。行列指数と複素常微分方程式を別実装し、移送・損失・残留の和を \(10^{-9}\) 以内で確認。 |
| 落下者の時間と反跳 | 三体の重力接近中の位相積分の係数を積分と有理数で照合。脱出円錐の \(1-\cos\theta\) を有理化。三種の放射図の規格化、二ヘリシティの特異値、五成分の最小固有値と角度積分を検査。 |
| 熱的な放射 | エネルギー保存する二モード・物質頂点を全Fockセルで直接発展。旧占有64と80の打切り、各セル確率の和、弱相互作用での付加条件付き解析式を照合。遠方一計数だけのときは、空振りでも残る偏極交換を含める。 |
| 弦・行列・関係 | 二住所それぞれの演算子でベル入力を発展し論理状態の忠実度を計算。行列の同時共役、実際の帰還での密度演算子計算と二人口の漸化式を12回まで独立に比較。異なる二つの八配位グラフで熱核を112点と152点で積分。 |
