# VER-0167　内部の形を緩めた半径と第五の力の検証

2026-11-24。RES-0180、DER-0180。[式](../derivations/DER-0180.md)・[計算コード](../../workspace/code/cat_flux_completion.py)・[数表](../../workspace/verification/cat-flux-completion-results.json)・[Lean](../../workspace/verification/CATFluxCompletion.lean)。

プロジェクト直下で次を実行する。Python、NumPy、SciPyと、同梱の前段の合金電荷・Hessian計算を使う。乱数種180。

    python -B code/cat_flux_completion.py

| 何を比較したか | 独立な求め方と結果 |
|---|---|
| 電荷と半径 | 巻付きから四種の電荷、ピン留めした平行源、鏡像、交差、奇行列の階数を整数で計算。24個の形を選び実電荷項の相殺を確認。ポテンシャルから独立に二階差分した全 \(3\times3\) Hessianの最大誤差は刻み0.004で \(2.67\times10^{-5}\)、0.001で \(1.67\times10^{-6}\)。再結合曲線上の位相の和と電磁勾配を別に検算。 |
| 強磁場の作用 | 周期シフトの交換子と折返し区間の差分二乗を直接照合した。可換でない二端のCayley固有位相に対して、空間差分・端の磁場・質量行列を別々に組み立てたHermite線形化の周波数を比較。12、24、48区間の低い四本の最大誤差は0.004335、0.001079、0.000270。多面での共分散補正と全次数の対称化則とのずれをGauss積分で検算。 |
| 平坦な場合の長距離力 | RR各次数の二階微分と正の質量固有系での射影不等式を変化させて検算。既存の合金電荷から同じ規約の \(\eta=2 Q_\oplus (Q_{\rm Ti}-Q_{\rm Pt})\sum_a g_a^2Y(m_a)\) を使用。比較した絶対値上限は \([1.5+1.96\sqrt{2.3^2+1.5^2}]10^{-15}\)。実験の専用の結合定数フィットではない。 |
| 負曲率とねじれ | 二平方和のHessianを差分し、独立に正準質量と固有ベクトルから有限地球のYukawa力を算出。整数 \(k_i=-2,\ldots,2\) の125組で実6次元の全Jacobi成分を計算し、非零高々一個の13組だけが通過。実構造定数からKoszul接続で単位計量のスカラー曲率を計算し \(-2\)。全七種の巻付き接線の李括弧閉包と全8個の偶形式の尺度重みを検査した。 |

追加項に必要な復元力は、均一球の二場の根とは独立に、正の球対称源の点源下限と \(m_c r=18\) で計算した。分布した軽場を含めた無次元光子の勾配上限0.056585と、二面を広げる方向の質量の必要下限 \(2.164\times10^{-13}\) eVが数表にある。

Lean 3.51.1で、巻付きが与える電荷の恒等式、奇周期の核、正の較正解の一意性と形状Hessianの正定値性、再結合の位相式、平坦・曲率ありの停留条件と二階微分の上下限、質量固有空間の射影評価と必要な復元力への逆算、二場の特性方程式、幾何フラックスの独立なJacobi成分と一般の \(k_i\) に対する積の制約、形の変形の重みと結合、磁場四次の係数、共分散補正、端の変分式の代数を検査した。実験の核モデル、木の縮約、弦ディスクの物理入力や相対角、無限行列・連続極限の存在はこれらの形式命題の仮定または外部入力である。局在バックリアクション、全開弦凝縮、CATでの起源は検証していない。
