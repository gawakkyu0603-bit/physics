# VER-0122　地平面の相対電荷、四重極、全質量の放出を再計算する

Python 3・NumPy・SciPy。作図時のみMatplotlibを使う。第2論文Z.17の奇パリティの動径積分を再利用する。数値入力、単位と規格化をプログラムに記した。乱数は使わない。

    python -B code/tidal_memory_release.py
    python -B code/tidal_memory_release.py --figure manuscripts/tidal_memory_release.pdf

第2論文の reproduction.zip には両方のプログラムが入っている。展開後、配布された数表を消した作業コピーで再計算するコマンドと、固定されたLean 3.51.1・mathlib3で検査するコマンドを示す。

    python reproduce.py sample
    python reproduce.py lean TidalMemoryRelease.lean --toolchain <ツールチェーンの配置先>

| 検査対象 | 根拠と結果 |
|---|---|
| 球面の電荷と局所読み出し | コンパクト接続のフラックス量子化とGauss–Bonnetを入力にした。整数の拘束、種数が共通の場合、正則な球内部への延長との衝突、誕生・消滅で許される電荷の組、零モードに対する局所入力の射影上限を形式化。半径10 mの首について、北端から首までのGaussian曲率を数値積分して \(2\pi\) と比較。二経路が半周する時間0.1047923 µs、丸い面では123.7911 µs。丸い面上で光速で到達できる円形領域の最大位相0.00256592ラジアン。 |
| 境界の応力 | 接合条件、Gauss方程式、Schwarzschild時刻一定切片の断面曲率を入力にして、異方的応力の下限を代数的に検査。三太陽質量、\(L=11813.0003\) m の例で \(8\pi GL|\Delta p|\ge97.1437\)。これは静止面のせん断応力条件である。時間依存する軸対称な面については別に周長半径の四元勾配と時間方向の接合を使った。この形状族で一様密度・等方的応力を満たすには半径比0.7087033以上。真の首は2/3未満なので共通解がない。 |
| 散乱の規格化 | \(r_s=1\)。無限遠と地平面の級数から奇パリティ波を積分した後、偶パリティへ変換。独立に偶パリティのポテンシャルそのものを用いて外部からDOP853で積分し、4周波数における外部インピーダンスの実部・虚部の規格化誤差は最大 \(1.07\times10^{-7}\)。単位流束のWronskianから虚部を評価。\(k=0.002\) の \(\Gamma/k^6\) は通常の地平面0.01789082、面0.01789024、漸近値 \(4/225=0.01777778\)。 |
| 四重極全域の熱的な出力 | \(\omega r_s=0.001\)–12の混合格子と、動径分割1400・2800の外挿。熱重みを掛けた通常の偶四重極出力 \(G^2M^2 P=1.90037\times10^{-6}\)。\(2\mu K=1\) の面はその0.0747281倍。全正の慣性を覆う有理関数の端点と四次式の物理的な実根を全周波数で検査し、周波数ごとの出力上限の積分比0.13744709。動径格子による変化 \(2.28\times10^{-9}\)、一つおきの周波数格子で0.13744703。いずれも数値精度の比較であり、厳密な区間積分による上界ではない。 |
| 先着記憶の量 | 有限な立上がりをもつニュースの二乗スペクトルに \([1+(k\tau)^2]^{-3}\) を使用。受信数を規格化振幅の二乗で割った値は \(\tau/r_s=1,5,20\) で0.0117844、\(6.7574\times10^{-6}\)、\(2.5832\times10^{-9}\)。同じ入射波の全粒子数は赤外発散する。積分の有限窓と全時間での識別を区別する。 |
| 跳ね返る面 | \(p=4/5\) の軌道について有理係数多項式の符号を部分区間のHorner評価で厳密に包囲。初めて速度がゼロとなる根が単純であること、再膨張時に \(P=1\) の解へ到達できることをLeanで検査。併せて \(p=0.76,0.80,0.86,0.90\) を計算した。\(p=0.80\) での折返し半径0.76616714、放出半径1.64699045、途中の最小外部ラプス関数 \(1-2m/R=0.116381\)。固有時間12.7560341、外部遅延時間23.6002316（初期半径単位）。 |
| 連続する終端放射 | 正の光度を2光横断時間にわたって出す例で、9時点の面積・質量拘束を直接評価。時刻積分でも最後の半径1.84108054を確認。瞬間放出、Born測度上の残留質量ゼロ条件、無圧力相の性質は別々に形式化した。終端でホーキング光度を仮定した際の面積増加は質量収支から計算する。 |
| 量子相関を運ぶ波 | 正則な平坦未来で一つの四重極の球ベッセル変換を有限区間のフーリエ積分と比較し、最大絶対差 \(2.50\times10^{-16}\)。単位半径で配置と速度に応じた放射エネルギー係数は \(5/2,\ 5/21\)、交差項ゼロ、正準形式の係数 \(10/21\)。ニュースの多項式の二乗とシンプレクティック形式をLeanで実際に積分した。二半径の分布による低周波補償も小波数で照合。 |
| 形式化の範囲 | 公開命題54、補助命題13。五乗の極限はフラックス式と外部散乱係数を仮定とした任意の収束列について証明した。閉曲面の幾何、Darboux変換、Einstein境界変分、Hankel変換、放射の量子化は既知の入力。Leanが扱うのはそこから用いた恒等式・符号・極限・積分・条件付きの存在であり、曲面の自然発生、完全な四次元の相転移や親作用を証明したわけではない。 |

四重極を熱的温度と結ぶ詳細釣合い、くびれが既に存在すること、物質が終端の波動データに移されたことは別個の仮定である。早い位相読取りと全質量の放出を、同じ作用が両者を起こしたとの判定には使わない。
