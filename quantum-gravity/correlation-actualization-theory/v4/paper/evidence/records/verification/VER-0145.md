| 計算 | 検算と判断できる範囲 |
|---|---|
| 変分とGauss制約 | 通常の四次力を矩形ブロックを含む元のHermite行列に戻し、差分で三次の誤差を消して厳密な極端偏極と比較。両方の向きで変位と背景速度に対する発散が零になる。別に \(\ell=2\) の時間ゲージ全成分を積分し、水平基底でGaussを消去した運動と終端の座標・共役速度を一致させた。 |
| 反対向きの量子幅 | スピン8、32、128、512、2048、四種類の配置で二つの独立な実初期値を発展。DOP853の許容誤差を変えて比較。負の曲率が全区間で続く配置では \(\cosh\) による解析的下限も確認。二時刻交換子からの下限は線形化の自己整合性の検査である。 |
| 非線形行列 | 一つの五色配置で二つの対角成分、全結合、Gauss、元の跡エネルギーと縮約式を直接比較。実計算では最大8192色の全鎖を速度Verlet法で進め、全ステップで二帯の識別と軸の交差を検査。刻みを半分にして比較し、報告した交差時刻は0.0002以内で一致した。線形量子幅の結論と古典的な非線形初期値問題は別々に検証した。 |
| 同じ向きの膜 | 接点のPauli全行列を相対スピン1から8で直接対角化。全階数での隙間は角運動量の端の式と内部の根号下限を使う。三対すべての二乗振動数下限には、32小区間上の単調な膜の端値と元の保存則を使う。大調波に一様な有限時間エネルギー評価も独立に実装。 |
| 有限時間の吸収 | 左の空状態と振動子の直接積分に加え、右の物質を終端から逆向きに駆動して全被占有準位に射影。スピン2では右の全入射準位から前向きに積分し、各ボルン重みの和と照合した。スピン128までは全対角化による負エネルギー射影、2048までは三重対角のレゾルベント積分48点と64点で照合。最大階数で時間積分の許容誤差も厳しくした。小階数では射影した交換部の全次数を直接ユニタリーに積分し、解析区間に入ることを検査した。 |
| 受信場所の区別 | 隣接する五つの参照膜に異なる軸・横位置を与えた。元の一回の入射・読取り窓で各単位交差を求め、全ての参照膜対を含む周波数下限と吸収を比較。五枚の確率を得る際、架空の追加コピーを数えていない。 |
| 入射量子を準備しない電荷移送 | 初期時計を0または受信窓の入口に置き、自由スカラーの交換子規格化を確認。生成過程の源に使う複素共役を吸収過程と区別し、窓の前後の振幅を同じ空間に戻して干渉させた。右の被占有準位を小階数で全対角化、大階数では各オクターブ8点・10点のレゾルベント積分で照合。広い配置のスピン128と2048で時間積分の誤差設定を比較した。2048の基準値には相対許容誤差を3×10⁻⁹から10⁻¹¹に絞った結果を採用。交差時の先頭重みの変化は約1.5×10⁻⁶（相対）、往復を含む解析区間の半幅の約1%である。一枚での重みと区間端は10¹¹倍した数値も保存し、小さい確率にも再現テストの相対誤差基準が効くようにした。これは精度を変えた数値比較であり、区間演算によるODEの誤差保証は得ていない。スピン8では、一枚の膜について全被占有軌道を初期から前向きにも運び、受信時の先頭振幅の重みと、射影した二部門での全次数の確率を検算した。一次の相互作用を含む初期準備は、背景を動かさないと仮想成分が一定に保たれることを確認。 |
| 特異点の相対軌道 | 両内部・両運動量のシンプレクティック伝播を二つの誤差設定で再計算。四次の相反特性式の根、固有ベクトルのシンプレクティック正規化、特異値、物質勾配による伸長の再現を検査。二本をもつれさせた入力と上限を達成する入力を別々に検査した。関連する潮汐領域の数値積分に対する区間演算による包含証明はない。 |
| 読取りと情報 | しきい値で二つの正規密度が等しくなることと、直接の積分による正答率を比較。有限モーメントの下限は規格化した密度に対する評価。非ガウス波束列の重なりは長さ4、8、16、32で隣接振幅からも計算した。 |

Leanでは四次ポテンシャルと座標差の微分、法線の二時刻交換子、二成分の不確かさから二乗平均幅への帰結、単一の電荷交差を保つPauli準位の算術的な隙間、磁気項の下限と膜間隔、射影した交換の誤差から確率区間への変換、二つの伸長と特異値の積からのガウス上限、有限しきい値の望遠和と存在、非ガウス列の漸化式を形式化している。入射量子を準備しない計算では、準備時刻からの三つの周波数下限に使う不等式、窓の振幅を重ねた干渉項、静止時の一次の初期補正、振動子エネルギーとそれを周波数の二乗で割った量の微分恒等式を扱う。Gauss制約の連続作用からの変分、通常のSU(2)スペクトル則、Robertson・Weylの不等式、ガウス忠実度の標準公式、有限モーメントによる密度上限と数値ODEはLeanの入力または独立計算である。一般の非線形な量子重力理論の安定性や相対論的因果性の評価は引き続き課題である。
