# VER-0144　行列物質の反跳、有限時間の局所読取り、二つの内部の軌道

2026-11-24。RES-0157・DER-0157・PLAN-0114。再現には [Python](../../workspace/code/cat_contact_recoil.py)、[基準数表](../../workspace/verification/cat-contact-recoil-results.json)、[Lean](../../workspace/verification/CATContactRecoil.lean) を使う。通常の物質発展は前節と共通である。

プロジェクトのルートから数値は `python -B code/cat_contact_recoil.py`。配布一式では `python reproduce.py sample` と `python reproduce.py lean CATContactRecoil.lean --toolchain <準備したツール群>`。NumPy・SciPy、Lean 3.51.1とmathlib3のコミット `65a1391a0106c9204fe45bc73a039f056558cb83` を用いた。数値計算に乱数、天体データ、ネットワークは使わない。

| 検査 | 独立な比較と成立範囲 |
|---|---|
| 法線座標 | 三項の逆慣性を元の八座標で計算し、解析式と照合。普通の軌道の運動エネルギーと質量直交分解が一致する。法線ポテンシャルには膜の半径の変化も含めた。 |
| エネルギー殻 | 独立な二準位例で開・閉・高エネルギーの五殻に対して散乱列の流束内積が単位行列。低階数解法と全行列の接続を比較。高エネルギーの先頭係数としきい値での反射も検査。 |
| 半充填の普通の物質 | 11,025成分、二つの入射ヘリシティ、より浅い打切り、最低打切りの全対角化で独立に検査。打切り4では平方根等の行列関数を行和で抑え、各二項級数の作用素尾部上限は \(1.36\times10^{-14}\)。接続方程式の残差、全確率とエネルギーを検査。全行列自由度への打切り誤差ではない。 |
| 空間的なポテンシャル | 点と膜の質量直交変位から元の物質・場・膜のポテンシャルを作り、両側の散乱を解いた。各側6、12、24分割で出力確率は0.001382232、0.001382235、0.001382236。内部準位を増やした計算で0.001382235。 |
| 有限時間 | エネルギー積分を224点と384点で比較し、境界値と空間微分を時間へ変換。入射・反射の干渉を保持し、粒子数とエネルギーの流れが時間積分点ごとに相殺。密度の積分と逆密度の積分から、線形読取り角の費用と状態別最小仕事を比較した。 |
| 自然なスピン | 低バンドの射影の有限差分と解析的な量子計量を照合。中性物質を交差前後の五面まで実際に発展させ、低バンド占有と固定軸スピンを計算。階数比較では裸の共鳴を直接検査し、色ホールの短時間強度をフェルミオン符号込みの占有基底で確認した。 |
| 一緒に動く受信膜 | スピン128、512、2048で、入口から出口まで二つのスピンと入射振動子を時間発展させた。スピン2、4、8、16、32では全軸ブロックを対角化し、隣接スピンで単位の指数変化、同一スピンで相殺を確認。スピン8の五膜では全中心幅0.0474351が各交差での競合準位との隙間の下限0.0517791より小さい。時刻順と吸収の先頭項を同じ準備・読取りで比較した。 |
| 特異点に由来する軌道 | 色の異なる二量子をそれぞれの正の光円錐運動量で伝播。シンプレクティック行列とガウス波動関数の重なり積分を比較。初期幅を1/2、1、2に変更し、一つの勾配に条件付けた復号を積分、両軌道・一軌道・一方向・無読取りの順序を照合。 |
