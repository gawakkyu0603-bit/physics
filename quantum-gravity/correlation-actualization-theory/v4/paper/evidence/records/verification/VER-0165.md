# VER-0165　回転する行列、電荷の極小、核の自由落下

2026-11-24。[RES-0178](../results/RES-0178.md)・[導出の規約](../derivations/DER-0178.md)・[一次資料](../literature/notes/cat-dyon-radius.md)。

| 検査 | 実施内容 |
|---|---|
| 回転は元の作用の解か | 六つの磁束で全18座標の勾配を円運動の加速度と照合。混合八偏極のゲージ直交性、全Hessianが外の成分を生成しないこと、回転生成子を含む16次元時間発展行列の極を解析式と比較。 |
| 静止した可換背景 | 非可換群 \(S_3\) の全六要素で実際の144次と576次の射影を作り、冪等性、状態数、二つの質量モーメント、四つの時刻の熱核、独立な数値積分とスペクトル和の \(-8\ln4\) を確認。 |
| 電荷が固定する成分 | 全38座標を動かした120例で右・左Gramの差、BPS下限と分解しきい値を比較。正準38次Hessianの二つの刻みで最大差は \(1.61\times10^{-7},3.92\times10^{-8}\) 以下（単位 \(\rho_*/M_P^2\)）。断片だけのHessianとアクシオンの二倍、欠けた電荷の有限変形を確認。 |
| 冷たい物質と膨張 | 等密度の三種で六半径が一緒に動く解に限定し、三つの荷電物質比率でFriedmannと動径の非線形方程式を積分。二つの許容誤差で現在変位の差は \(10^{-8}\) 未満。膨張史や粒子密度を観測から当てはめたものではない。 |
| 普通の物質が感じる力 | 電磁寄与に限定し、核電荷・二つの合金・地球の源電荷から自由落下を再計算。RR三形式の21の独立計量変分、有限な共通尺度変換、120通りの矩形トーラスで整数電荷の質量下限を検査。 |
| 核の項による相殺 | 一つの開弦ゲージ作用に光と色を置き、原著式(73)–(76)の全感度、地球の源、四つの試験物質を使用。二試験の勾配の行列式から走りの全範囲に成り立つ下限を求めた。表面項を0.9、1、1.1倍した計算を比較。 |
