# VER-0157　フラックスを保存する履歴、多数層の形状、落下物質の電荷

2026-11-24。対象は[RES-0170](../results/RES-0170.md)と[DER-0170](../derivations/DER-0170.md)。[多数層の計算](../../workspace/code/cat_layer_contacts.py)・[整数表](../../workspace/verification/cat-layer-contacts-results.json)・[物質電流の計算](../../workspace/code/cat_tidal_current.py)・[数表](../../workspace/verification/cat-tidal-current-results.json)・[Lean](../../workspace/verification/CATTidalCurrent.lean)。

| 対象 | 手段 | 確かめたこと |
|---|---|---|
| 任意の層数での共通変形 | 最初のフラックスの有理数核を計算し、共通尺度を除く。各相手による制約の次元を整数のGram行列の主小行列式と数値特異値分解で比較。直線と平面は互いに素な整数ベクトルで表示 | 49軌道と12,048配置。全組で尺度を保つ。整数積の64ビット上限を確認し、組数はPythonの多倍長整数を使用 |
| 包含関係を使った計数 | 小さな二次元・三次元の有理数行列集合で、全組の行列を縦に連結した直接法と一致。3次元では新しく生じる平面の交線を含めた。乱数種1305、残りの配置1個から3個まで全列挙 | 一層の全内訳、二層の従来の整数計数を完全再現。各層数で全次元の度数の和が \(12048^n\)。全次元の度数から得た \(T_n\) と七つのべきの式を \(n=1,2,3,4,6,8,12,20,32\) で照合。大きい \(n\) は数値外挿せず同じ包含式を使用 |
| どの形が残るか | 9本の座標方向と一つの対角差を、12,048配置すべての元の外積行列に直接代入。二配置の実例は連結行列の有理数核でも照合 | 三つの対角軸各1,840、非対角各64、二軸の対角差672。対角二軸を許す配置は三軸とも許し、その数は672。数表に共通尺度だけを許す二フラックスの全成分を保存 |
| 波動関数と保存電流 | 正負二運動量のSchrödinger方程式を別に積分し速度頂点を時間積分。Bloch終点式と比較。非零内部対で電流を反転するユニタリーと、無限線形掃引の誤差関数を独立な求積で確認 | 物質のギャップ0.25で、地平面の各準位の電流の求積・時間刻みを変えた最大差 \(4.3\times10^{-9}\)。負エネルギーの海と温度を持つ準備を別に計算 |
| 潮汐の角方向 | 振幅を正負に変え、0.16から0.02に半減しながら対称差分。回転対称準備の解析的な一次変分と比較 | 全電流の見掛けの一次項が0に近づく。動径準位の一次係数は約 \(-0.00154\)、全準位の二次係数は約 \(1.46\times10^{-5}\) |
| 開端と補償 | Cayley中点の各出力で粒子数の変化を切断面の電流積分と照合。規格直交性、左右の端状態のエネルギー、半無限の試行波束の有限長での残差を検査 | 連続式の絶対許容誤差 \(2\times10^{-11}\)。時刻 \(1.5r_h\) の同一読出しで、落下0.11805952、平坦0.11841332。凍結ハミルトニアンでのエネルギー保存と、受信器を含む四次元の動的保存は異なる |
| 数値精度と物質の境界 | 同じ128点で440と880の時間分割を比較。物理長9.6を保って96点・間隔0.1と128点・間隔0.075を比較 | 地平面の対の確率の時間精細化差 \(1.8\times10^{-8}\)、空間精細化差0.00046。鋭い空間電荷の全変動距離は同じ空間精細化で \(6.00\times10^{-5}\) から \(6.93\times10^{-5}\)。その絶対値や鋭い読出しの仕事を連続理論の普遍量としない |
| 残る信号時間 | 有限鎖の最低線を二重対角行列の最小特異値から求め、時間積分を交差前後に分割。単一量子の同じ包絡を仮定した位相幅を用いる | 到達する地平面で位相幅0.02364 rad。初期からの一粒子の質量差の時間積分は0.05286。後者は多粒子全体の距離上限に使用しない |
| 場のエネルギーと未知状態 | Gauss則で除去した電場の正のノルム評価。二重項の全行列を磁気並進で平均。重力放射の総エネルギーを最低帯域量子で割る | 非零ゲージ結合で固定効果の確率の連続性を保証。コードの回復には個々の隠れた出力が対称性を保つ要件がある。粒径0.1 mmの帯域上限は総放射の先頭近似に基づく |

Lean 3.51.1での対応は次の通り。履歴の長さに関する帰納法でフラックス射影を保つこと、層数を問わない共通の尺度と二つのフラックスによる形の制限、部分空間を含む順序組の個数、厳密な包含部分の引き算、列挙から得た七係数の任意次数における二表現の一致、3層での整数値を形式化した。電流と時間微分の関係、積分、トレースレスな形の一次変分、端の正規化条件、Gauss則、有限時間の摂動評価、同じ固定測定の可換性、二端の不一致範囲、磁気並進と放射帯域の上限を含む。軌道と有理核の具体的な入射度数は整数プログラムで得た入力である。微視的な物質の選択、外部Schwarzschild解からの全崩壊、時間発展の数値そのものがLeanの定理であるとはしていない。誤差関数、自由フェルミオン統計、量子回復条件の物理的な原典は[文献ノート](../literature/notes/cat-tidal-current.md)にある。

第5巻の再現ZIPは付録O.2の多数層計算を sample に採用した。電流のプログラムも同梱し、同じディレクトリ内の付録O、O.1のコードを使う。研究ルートでの実行は以下の通り。

~~~powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:MKL_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
python -B code/cat_layer_contacts.py
python -B code/cat_tidal_current.py
~~~
