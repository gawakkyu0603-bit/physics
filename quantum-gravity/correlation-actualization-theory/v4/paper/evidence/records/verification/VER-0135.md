# VER-0135　物質の帰還、行列時計、四次元の潮汐と脱出円錐の検証

2026-11-23。対象 [RES-0148](../results/RES-0148.md)、[DER-0148](../derivations/DER-0148.md)。Python、NumPy、SciPy、Matplotlibを使用。形式化はリポジトリにあるLean 3.51.1とmathlib3の固定版。配布用ZIPのマニフェストが対象ファイルと検証手順を指定する。[計算コード](../../workspace/code/cat_relational_waves.py)・[参照数表](../../workspace/verification/cat-relational-waves-results.json)・[Leanファイル](../../workspace/verification/CATRelationalWaves.lean)。

## どこまでを機械で確認したか

- 二組のワイル交換関係をもつ微分作用素を有理数係数の多項式で実現。\(f=u^2/2,\ a=u+u^2/3,\ b=u^2/4\) として、六つの二重交換子を各28個の単項式に作用させ、全ての係数が厳密にゼロになることを確認した。任意の関数の論拠は、関数の値で可換になる項と調和二次式の一般的な交換子恒等式である。
- 原始的な四変数で六行列の埋込みの微分から密度、計量、クリストッフェル記号、リーマンテンソルを計算。真空条件を満たす場合と外す二例、三つの座標点、二つの差分幅で、リッチテンソル全成分と横方向の潮汐行列の全成分が解析値との差 \(1.2\times10^{-6}\) 未満だった。原点の無跡潮汐も直接確認。逆偏極の式を使う検算とは計算経路が異なる。
- 二偏極に異なる時間依存を与え、五単位長の区間で逆問題を積分。41点で解の独立な中央差分から偏極を再構成し、絶対誤差 \(4\times10^{-9}\) 以下。測地線偏差方程式の解は終端の相対速度が非零で、保存されるロンスキアンも \(2\times10^{-12}\) 以内で閉じた。数値サンプルのみから任意の波形について結論していない。
- 四面体の二準位への等長埋込みと三つの位置演算子を直接計算。全八準位のスペクトルで有限ギャップ時とギャップを外したときの指標を比較。セシウムに働く重力は二球の外部の厳密なニュートンポテンシャルからフーリエ積分した。小さな配列ではほぼ等しいポテンシャルの差を有理化し、主要四重極項とも比較した。
- 二粒子は四つのモードに生成演算子を二度作用させて占有分布を計算。電荷を分ける場合とまとめる場合を比較。四受信体と逆向き二壁の厳密確率も照合した。測定精度の参考として、二群の期待値の差が少なくとも0.40あり、判定の中点が既知、独立ベルヌーイ反復とした理想例では片群116回のときHoeffding両群上限 \(2e^{-116(0.40)^2/2}<0.001\)。これは実験の系統誤差や実機での有意差の見積りではない。
- ブラックホール計算では光線そのものと横偏差を別々に積分し、51点で角度由来の分離 \(r\sin\phi\) と一致することを確認。自由落下座標で脱出円錐を再構築し、三つの放射半径で臨界衝突径数と照合した。出力は全天球への到達上限である。

[Lean](../../workspace/verification/CATRelationalWaves.lean)は非可換環上のヤコビ恒等式と二次調和式、時計の両順序の一致、四次元運動項の代数、真空曲率の相殺条件、二偏極の逆行列・回転・有界性、初期状態の余裕、有限区間での逆方程式の存在評価、受信統計と階数による回復上限、光線のヤコビ式と脱出円錐の変形を検査する。区間存在の形式化には、時間連続性と球上の一様リプシッツ性を明示的な仮定として与える。今回の滑らかな駆動関数にはコンパクト性と標準的な微分評価がこれらを与える。Leanは一般相対論の曲率テンソルの実装や無限次元の量子作用素の自己共役性、実験装置が実際に重力を書き込むという物理仮説まで一括証明するものではない。実二次発展の作用素論の入力は[一次文献](https://doi.org/10.4171/JST/149)、幾何テンソルは別経路の数値計算で照合した。

## 再現手順

プロジェクト直下で三つのBLASスレッド環境変数 OPENBLAS_NUM_THREADS、MKL_NUM_THREADS、OMP_NUM_THREADS を1とし、次を実行する。

~~~text
python -B code/cat_relational_waves.py
python -B code/cat_relational_waves.py --figure manuscripts/cat_relational_waves.pdf
~~~

配布用の第4論文の reproduction.zip を展開した利用者は、同梱の reproduce.py の check、sample、lean CATRelationalWaves.lean を使える。全試験に乱数は不要。行列時計は無限階数の連続スペクトルのセクター、計量は長波長・古典プローブ近似、四面体の時間は有限ギャップ、共鳴、外部球に対するニュートン重力の例、脱出円錐は球対称真空・幾何光学の結果である。有限行列の実験装置がこの重力端を実装すること、一般の四次元量子重力や放射による全状態の回復は検証されていない。
