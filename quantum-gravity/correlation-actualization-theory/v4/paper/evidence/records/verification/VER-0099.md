## 数値と異なる計算方法の照合

| 対象 | 照合方法と得た精度 |
|---|---|
| 有限時間のパケット | 指数核とその一次多項式倍を各対のセルで解析積分し、別の実積分と照合。64、128セルで同一入力の制約付き最短時間は \(d=1/4\) で3.39673、3.39572。\(d=2/5\) でも同じ表示精度。3.40は数値推定。時間上界と \(\Gamma T=5\) の具体的な純粋パルスは独立 |
| 同一期間内に応答が完了する条件 | 固有値方程式と、無限未来のグラム核から終了後の自由減衰を引いた128セルの直接固有値を照合。5種の時間で相対差 \(6\times10^{-5}\) 未満 |
| Schwarzschild | 奇・偶の波動方程式を異なるポテンシャルで直接積分し、微分によるDarboux写像と比較。二例の相対誤差 \(2.4\times10^{-13}\) 以下。遠方接続半径と級数次数を変えた四重極の透過パワー差 \(8.5\times10^{-12}\) 以下 |
| 偏極の角度 | スピン荷重加法定理とRegge–Wheelerの \(\ell=2,\ldots,8\) を合成。上限を7に下げた5周波数の交差角差 \(4\times10^{-5}\) 度未満。低周波の単一四重極極限 \(\cos^4(\theta/2)\) と比較。地平面では正則な入射解を地平面展開から両側へ別々に積分 |
| 中性穴の印 | 二つの反射位相差を複素散乱振幅から計算。積分次数60、86。\(x>2.2\) の四重極の残りは \(6.24\times10^{-14}/r_s\) 以下。全多極上限の重み和は \(1/108\) |
| Reissner–Nordström | \(2M=1\)。同じトータス位相原点で二つの複素振幅を接続し各チャネルの流束を確認。代表点で接続距離・次数を独立に変更。全帯域の二受信は52、76点。容量は透過率1/2の周波数で積分を分割し、各区間24、36点で照合。高周波端 \(x=3\) での寄与はプランク因子で指数的に小さい。全帯域は正周波数の積分を指し、全角運動量の和を意味しない |
| 観測者の存在による選択 | 同じ四重到着を基準に、最初の物質記憶が保持された場合と全試行の後続二粒子を比較。ガウスの24置換を合計し、保持・消失の重み付き平均が全試行に一致すること、同時極限の24置換の係数と符号付き差を形式化。\(v=9/20\) の有理数で同じパルスがもつれ判定をまたぐことと、保持条件を確率的に緩めた限界 \(41/132\) を検査 |
| 原子の書込み | 電気四重極の横波射影を球面で積分し \(1/5\) と照合。水素型動径積分でE1・E2と重力四重極を得た。符号を反転する電荷共役対と同一組成の二つの結合行列を比較。\(1s\to3d\) 二光子による誤認は実験原著と照合 |
| 未観測の軟放射 | 中性の安定な吸収体に対する先頭軟重力電流を積分した。1次元の閉形式とテンソル偏極2成分の球面積分を独立に比較。二光子の場合は入射方向で積分域を分割し180・320点で照合、表示した三つの開き角の指数差は規格化後に最大 \(1.2\times10^{-7}\)。共線での電流一致と有限分解能の反跳上界をLeanで検査した |
| 行列と関係からの源 | BFSS三次行列の積と二本の縮約運動方程式を別々に計算。保存エネルギーの数値ドリフト \(9.5\times10^{-12}\) 以下。微分の小行列式は有理数で \(-1280\)。関係グラフの親演算子は \(L=1,2,4,8,16\) で基底状態・励起ギャップを検査。有限の \(L\) にも適用できる漸化式を別途形式化 |

## 形式化との対応

- 非ガウス入力の反対称二体振幅は可換な消滅演算子の多項式として検証した。随伴を取った後はノルムの積と正規順序の真空条件を用いる。直列伝達、正規化した二受信の閾値、熱光の縮約、単一キャリアのボルン則を仮定した保存因子、局所利得がない場合の消失の生成式を含む。
- 有限時間のもつれ判定多項式、正規化二乗積分と積分核の上界、同じ入力を使う双対の弱不等式を検証した。数値最適化の小数値や任意のブラックホール時空を定理とする形式化ではない。既知のガウス通信容量、球面調和関数の加法定理、整合切詰めは出典の結果を利用した。
- 電気・質量四重極の質量係数、蛍光率の係数80、分岐後の全崩壊の完全性、二光子の共線条件、単一光路の減衰が1/2以下となる荷電比、行列源、エネルギー固定連鎖を含む。Leanの仮定は原稿で明示した物理的境界条件の代用ではない。
- 検証対象は第2論文の付録T。原稿と書誌は配布用LaTeXアーカイブから3回組版し、著者、フォント埋込み、重複ラベル、参照、ページ内の境界、配布PDFとのバイト一致を確認した。全185頁、付録Tは160–171頁。第2論文用の再現ZIPからは `python reproduce.py sample` がこの新しい計算を実行し、`python reproduce.py lean CausalRadiationContacts.lean --toolchain <環境>` が同じ証明を検査する。
