## 独立に突き合わせた量

| 対象 | 検算方法 |
|---|---|
| 可逆な電流 | ボース占有基底で三次演算子を作って対角化した。準位4、7、11、15の全てのモードを二つの時間でフェルミ粒子・正孔の解析式と比較。最大差は \(5.2\times10^{-15}\) 未満。 |
| 不可逆な電流 | 準位4、6、8の全演算子空間で生成子を対角化し、零モードの個数と変分上限を照合した。遅い固有演算子の正負部分から初期状態を作り、緩和時間の2倍でトレース距離 \(e^{-2}\) を再現。9900通りの非順序対の二モーメント変化に衝突なし。 |
| 放射の軟化と所要時間 | 小さい準位では生成関数から得た重みと行列の二乗ノルムによる変分上限が一致。大きい準位はオイラーの五角数漸化式と整数係数の畳込みを使用。準位6400、モード34の放出／逆吸収比は0.3392577、漸近値0.3361602。 |
| 初めから相手が決まっている左右の電流 | 二つの独立な分割の最小占有数を準位8で全列挙し、尾確率の二乗の和に加え、放出できる全エネルギーの分布を共通部分を除く分解と比較。残存エネルギー割合は準位100で0.74408、6400で0.74938。余分な相手との放出幅比2/297で最初のスペクトルの相対差が1%、最後の一対の生存率が1%になるまで通常の逆幅の683.87倍と検算した。 |
| 三つの端が発する量子 | 四重極の角度を積分した結果を縮約公式と比較。規格化した行列の固有値は \(3/4,9/8,9/8\)。それぞれの端に同じ操作を施す演算子から構成した6種の履歴の36通りの積を実際に符号に圧縮した。スカラー行列からのずれは \(3.2\times10^{-16}\) 未満。 |
| 短い環からの移送 | 準位1–3の短い電荷・左右の長い電流・放射損失を持つ発展演算子の減衰指数を直接計算。準位1で短い環から始めた行列指数を臨界減衰解と比較。放出幅の逆数の20倍後にも \(61 e^{-10}\) の未放出確率がある。 |
| 普通の潮汐結合と時間 | \(1/d\) の四階微分テンソル81成分と二組の振動子の行列要素を作り、三端の標準表現の交換率を解析式と比較。人体質量と可視粒子質量の二つの受動的な受信器が共鳴条件にあっても、利用時間内の交換確率はそれぞれ \(2.09\times10^{-44}\)、\(7.31\times10^{-42}\)。 |
| 有質量波の到着 | 三つの閾値（質量ゼロを含む）と三つのラプラス周波数で、連続スペクトルの積分と平方根を比較。有限長の振動子4万個の和を双曲余接と突き合わせ、誤差が解析的な尾の上限内に収まることを確認。反射の時間領域のベッセル核を再積分して \(-\exp(-2L_b\sqrt{s^2+\mu^2})\) と照合。 |
| 四次元の収縮と放射 | 加速度・エネルギー・遅延時刻を含む5変数の微分方程式を指数1、2、3、5で独立に積分。初期の質量と全動径放射を比較し、球面での曲率の減少・発散・有限非零を区別。角運動量の和が1、100、\(10^6\) の条件で外側の反転点を求め、無限遠への遅延時刻を求積した。1の行は幾何光学の適用域外。 |

## 形式化した主張と物理入力

[SoftChargeRelease.lean](../../workspace/verification/SoftChargeRelease.lean) は、粒子・正孔の振幅差と低周波エネルギーの上限、有限の複素行列での交換子の随伴・トレースと、正の記録率で散逸がゼロなら全ての電流と可換になる条件、分裂ラベルの一意性、多項式による遷移の射影、任意の正の部分の分割への到達と可換作用素のスカラー伝播を扱う。この際、実線形空間についての結果は複素状態空間を実数に制限して用いられる。順逆遷移の比と時間比、三端の複素振幅の射影、四重極の正のグラム形式、残存率の非負和、臨界減衰の微分方程式、通常の物質の交換率と有限時間条件も検査する。

二組の分割で共通する部分の有限個数・独立な尾確率、放出されずに残る個数、全エネルギーが出る場合の二分割の一致と対角集合の確率、分割数の近似を重み付き和に用いる不等式とその極限、四つの組合せを開いた場合の正の放出率、余分な相手がある場合の初期スペクトルと1%の幅の条件を形式化した。分割数の局所漸近と裾の近似にはHardy–Ramanujanの定理を使う。

境界応答については、紫外発散を除いた被積分関数の分解、原始関数と有限区間積分、連続応答の正規化、離散重みと最初の反射の代数、往復の時間条件を形式化した。四次元では、電荷密度のロジスティック解、質量流出の積分、終端の曲率と座標微分の上限、反跳による対数の傾きの積分・指数下限、反転の臨界質量とコンパクトネスを検査する。

正規順序化した電流のボース・フェルミ対応、分割数の漸近定理、誤り訂正の定理、四次元の球殻の接続条件、波動方程式の有限伝播速度は文献・場の方程式からの入力。Leanの定理は指定した関係からの帰結を対象とする。量子場の構成全体、灰色体因子の大域的な解、自然物質がこの作用を持つことや最後の一量子の回収は形式化されていない。
