検証はPython・NumPy・SciPy、図の生成はMatplotlib。行列基底の乱数種は142、入出力ハミルトニアンの比較は1839、未知状態の試験は49を固定する。数表の参照計算はBLAS 1スレッド。Lean 3.51.1とプロジェクトのmathlib3固定版を用いた。

| 検証対象 | 独立した確認と範囲 |
|---|---|
| 重力記録を運ぶ指標 | 全スピンに対する二次ブロックの行列式、負符号と端の符号条件をLeanで確認。別に9個の16成分クリフォード行列と全16成分のスピン結合を生成し、階数2,3,4,7,12、内外および色基底の無作為回転で比較。面外のギャップの二乗も照合。 |
| 自由落下と直接作用 | 行列球の古典収縮を積分方程式とODEの双方で解いた。Landau–Zener率を二つの有限時刻窓で時間発展と比較。共通通路の正の和と細分化を検証。二つの具体的な物質準備で行列指数を直接計算し、近傍の内部確率1、遠方の内部確率は解析上0で数値 \(2.47\times 10^{-32}\)。 |
| エネルギーと確率 | 入出力のハミルトニアンを異なる非可換な行列とし、4種類の正のエネルギー差をコヒーレントに合成。全エネルギーの各スペクトル射影の双対チャネル残差は \(9.37\times10^{-16}\)、完全性の残差は \(1.05\times10^{-15}\)。Leanでは各成分の全エネルギー一致、任意のスペクトル関数および完全なKraus族での保存を検証。 |
| 書込みとAの回復 | 二つの正負の界面出力がそれぞれ1/2で、入射条件付き未書込み確率0、どちらにも完全な入力の二成分が残る。異なる絶対エネルギーを含むAと基準のBell忠実度、二回の公平な隠し記録の排他的論理和も試験。全ての自然物質状態を回復できるとは仮定していない。 |
| 超対称性 | 16個の生成子について反交換関係全組合せを検査。256次元長多重項で単一偏極の種を射影し \(I/256\) になることと全生成子との交換を検証。Leanで反交換の二重符号の相殺、各平均の不変性と既存の不変性の保存、率の規格化を検査。ローレンツ対称性、中心電荷付きBPS多重項、一般の局所超電流の検証は別課題。 |
| 四次元プローブ | \(\mathrm{End}(V_j)\) の随伴ラプラシアンを階数2,4,7,12で全対角化し、\(\ell(\ell+1)\) と縮重度 \(2\ell+1\) に照合。階数128まで熱核を計算。回転する膜を \(\tau\in[0,15]\) の2001点で独立積分し、保存エネルギーのレンジは最大 \(6.35\times10^{-12}\)。2%未満と大きい初期変位の違いは数表で読める。Leanで縮重度の総和、計量の密度係数、曲率の代入、積計量のEinstein係数、優勢エネルギー条件の窓と巻き弦の張力条件を確認。一般相対論やスペクトル収束定理全体の形式化ではない。 |
| 弦の灰色体 | シュワルツシルト動径方程式で刻みを2段階変え、四次外挿と独立の軟極限を比較した。裸の中性弦の有限周波数失敗と、補正後のタグの一部だけが有限時間で回収される量を別々に記録。 |
| 別の量子重力 | 四価SU(2)不変節点で符号付き体積とその絶対値、離れた二つの因果的書込み順序、CDTの忠実な詳細釣合いの反例を検証。これらは各理論全体の等価性を試験したものではない。 |

回転する源と受信膜について、6周期の滑らかな潮汐パルスを用いた。通常の二次作用の二つのシンプレクティック発展を直接積分し、一対生成の摂動論と比較した。ピーク潮汐が受信周波数二乗の0.002なら、半径比1と1.18で受信確率はそれぞれ0.000266440と0.0000000999948。入射パルスの強度や向きはこの計算の初期・境界条件である。

Leanファイルには53個の定理があり、追加公理や未証明の穴を用いていない。主張のうち既知の膜指標や量子誤り訂正定理、BFSSと弦の双対性に関する物理的入力、一般の宇宙への適用範囲は[原著との照合](../literature/notes/layer-matrix-parent.md)を参照。
