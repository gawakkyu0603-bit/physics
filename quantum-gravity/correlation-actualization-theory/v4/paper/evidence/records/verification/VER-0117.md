| 確認した対象 | 独立な計算と判定 |
|---|---|
| 二つの時計 | シュワルツシルトの落下測地線と入射光の advanced time を積分し、その後に静止面の固有時計へ変換した。3つの半径の結果を保存。 |
| 四つの質量変化 | 入射の正周波数解から時間依存振動子を複素振幅で数値積分し、出射係数の二乗比と解析式を照合。ロンスキアンの1からのずれは \(1.9\times10^{-11}\) 未満。 |
| 内部時計と物質 | 四つの実振動子の真空モードと時計を同時に発展させた。初期余力を0、0.08、1に変え、転回・横断と生成エネルギーを比較。総エネルギーの最大変動は \(4.9\times10^{-12}\) 未満。 |
| 放射行列 | 二種類のボース占有基底で左右それぞれ一対から八対までの全行列を構成。複素放射行列の放出・逆吸収と、トレースゼロの三経路の最低固有値を解析式に照合。無放出の状態空間の次元も全固有値から求めた。 |
| 回転する放出口 | 非可換な時間依存の放出を直接積分し、基準露出4.06781、必要下限2.59813、残存0.04514を得た。 |
| 共鳴と最終電荷 | 臨界結合での解と二成分の行列指数が一致。一単位が残る実際の半径で計算を切る。幾何を通じて変わる周波数差を含む無放出の微分方程式と流出確率を同時積分し、規格化と共鳴時下限を各枝で検査。終盤の微小確率は \(b/X,\ P_{\rm out}/X^3\) を独立に積分して数値の桁落ちを避けた。 |
| 完全交換の場合と経路記録のある場合 | 二つの環境ベクトルと入射経路の振幅を直接足し、境界側と放射側の確率の和が1になることを確認。経路の記録が直交した例では半分が残る。 |
| 四次元の電磁応力 | 通常のマクスウェル場から直接計算した法線応力・移動面を通るエネルギーを積分。部分積分後の四次式、近接場の蓄積を含むエネルギー恒等式と比較した。零力積の波形で数値残差は最終エネルギーの \(1.6\times10^{-13}\) 未満で、開始時刻をずらすと符号が反転する。両端の傾きがゼロの変分解は、根を求めて別に積分すると残差が約6.45×10⁻¹⁴だった。 |
