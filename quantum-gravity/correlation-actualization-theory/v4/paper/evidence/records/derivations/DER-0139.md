# DER-0139　荷電線への有限時間遷移と、戻る量子を含む放射路

2026-11-23。本文の計算とその適用条件を以下に対応付ける。論文本文・[前段の作用](DER-0138.md)・[再現手順](../verification/VER-0127.md)。

| 出発点 | 導出と用途 | 成立するための条件 |
|---|---|---|
| 反対向きの二部位からなる一重項。球面で同時に到来する先行計算の方向場 | 同順序なら \(P_-\otimes P_+\)、反対順序なら交換 \(S(P_+\otimes P_-)\)。一重項では二つのベクトルが符号を除き等しく、面と伴侶の射影は \(P_-,P_+\) に定まる。 | 通常の一重項の準備、重力によるボルン接合、実際に同じ軸を受け取れる二部位。未知の荷電物質を無条件に投影する規則ではない。 |
| 測った方向が物質の空間的な面の法線 | 面に適合する空間スピンフレームで横二成分は射影で消え、接続の重みは \(-1/2\)。種数 \(g\) で相対電荷 \(g-1\)。立体角とGauss曲率の面密度を別々に計算できる。 | 既存のスピン幾何とGauss–Bonnetを用いる。曲がった空間では周囲のスピン接続を含める。単なる次数1の場に置き換えると一般に積分のみ一致。 |
| \(j\) の方向基準と一重項への入力等長写像 \(A\) | 合成スピンの小さい射影 \(L\) に対し \(A^\dagger LA=q1,\ q=j/(2j+1)\)。直交する出力 \(V_l,V_h\) を \([L,AA^\dagger]/\sqrt{q(1-q)}\) が回す。一方の結果を四分の一回転させれば、入力によらず厳密に \(V_l\)。 | 実際に受け取った有限の方向基準。スピンを単独で完全反転する操作ではない。最高ウェイトの回転軌道で接続の差をとることが境界の新しい結合仮説。 |
| 同じ \(j\to j-1/2\) の遷移と随伴する放射 | 残りの下向きスピン数を \(k\)、全数を \(n\) とすると、各分岐の二乗は \(k/n,(n-k)/n\)。全順序の分子は \(k!(n-k)!\)、分母は \(n!\)。放射の異なる \(k\) は直交し、完全な等長符号になる。 | 固定された多重項、分けられる出射モード、磁気状態を漏らさない重力記録。異なる \(j\) は初回の消去不能な結果から既に識別され得る。 |
| 潮汐ストローク後に単一電荷へ二度ずつ接触する二つの光路 | \((D_RUD_L-D_LUD_R)/2\) は \(SZ\) に比例。線形伝達関数 \(2as/(s+a)^2\) を入射指数波形に掛ければ有限時間の確率が得られる。 | モード整合・無損失・通過順・独立試行を明記。有限の重力波だけによる厳密識別という前段の反例を回避したとみなさない。 |
| 通常の電気双極子による出射と未観測の中間方向 | 二階・四階の等方角モーメントで四重極成分が7/10倍となる。片側の清浄な光子を制御に使い、最後の方向別に特異ベクトルを合わせるとトレースノルム上限を達成。 | 二光子符号の特別な構造。一度目の再放出方向は光にも残る。途中の方向記録が最後に光へ戻る場合は、別のチャネルとなる。 |
| 失敗ごとに確率 \(p\) で方向履歴を残し、確率 \(t\) で脱出 | 再帰 \(V=t+(1-t)(1-3p/10)V\)。双極子で \(t\propto x^4\)、\(V\to1\) には \(p=o(x^4)\)。全応力の一例で相対重力放射の量子数は \((4/5)t_P^2\omega^2(d/cT)^4\)。 | 重力の非真空成分の読出しは二経路の識別に関する上限。連続方向を完全識別することを仮定に埋め込まない。 |
| 二光子の応力テンソル頂点、巨視的な小ギャップ | 各光子の周波数の三乗と、他方の三乗の積が一光子分布。非負のギャップ測度を積分すると \(H=F/x^3\) は凸となる。 | 全強度は自由。外部伝搬・単一光子周波数に依存する頂点・非球対称性は別に調べる必要がある。 |
| 標準の透過率を放出後に独立に掛ける仮説 | 軟領域で \(H_0^{(4)}/6\sim140 x^{-8}\)。カットした総エネルギーが \(\delta\) 未満の対の影響は、出射数とエネルギーでそれぞれ4次と5次。 | 同一周波数で無限に再試行し、最終的に貯蔵を空にするなら、注入と脱出の積算は一対一。ホーキング重みを一回の透過と全履歴に二重適用できない。 |

採用した仮定のうち、荷電面を点ごとに満たせること、ボルン分岐後の量子状態、放射分布の必要条件は検査可能な数学的関係である。重力による射影の絶対率、オンの時刻を自然に定める微視的作用、恒星内の受信集団、蒸発時の全質量・量子相関の同時収支は依然として未同定である。
