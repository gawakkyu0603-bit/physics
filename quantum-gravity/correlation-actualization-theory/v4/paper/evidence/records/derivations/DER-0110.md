# DER-0110　物質の量子相関をホーキング放射へ移す作用

2026-11-22。状態 CONDITIONAL。関連 [RES-0110](../results/RES-0110.md)、[検証](../verification/VER-0098.md)、[先行研究](../literature/notes/hawking-correlation-transfer.md)、第2論文付録S。本文の結論に影響する仮定は、通常の作用が生成した実在の重力交換、交換が起きた場所での私的な層分離、荷を運ぶ物質と放射の因果的接触である。物理定数の導出は後段に置く。

## 何が候補を区別するか

通常の作用 $S_0$ で起きた実交換の振幅密度を $M_o(y)$ と書く。重力結合の行列要素・物質の形状・終状態の位相空間がこれを定める。散乱なら四元運動量保存を表すデルタ関数と反跳体を含む。区間内の無交換も合わせた正規化は $\sum M^\dagger M=1$。交換ごとに二重経路積分の両枝で私的ラベルを一致させ、各ラベルの密度演算子を直和する。これは普通の開放系の記述からは出ない付加則である。他の宇宙のラベルとの一致を要求しない。運動量に連続部分があれば、一度の交換で層のボルン測度が連続になる。単位時間に無限個の検出が起きるという仮定は置かない。履歴を残す、置換する、逆交換で消す、という区別はこの直和の更新則にある。

下表の選択は同一の現象を説明する競合案と、組み合わせられる作用項を含む。「固定係数」はその作用を選べば自由な率定数がないことを指す。既知の原理による一意性を意味しない。

| 候補 | 発展則に入れるもの | 絞り込みの根拠と残る条件 |
|---|---|---|
| 全反跳の連続選択 | 実交換で $d\nu(q)M_q\rho M_q^\dagger$ を直積分 | 連続無限の層と絶対微分率が同じ振幅から出る。無限に軟い重力子には有限な包括的受信を使う |
| 沈着エネルギー | 受信体が区別したエネルギーのスペクトル射影 | 同じエネルギー内の方向を保持できる。受信物質の未観測自由度が方向を持てば追加のトレースが必要 |
| 符号付き角運動量 | 吸収体への角運動量移送を、物質自身が提供する軸で分解 | 軸を持たない源に絶対方向を仮定すると回転対称性を破る |
| 回転不変な選択 | 角運動量の大きさ $J$ のみを分解 | スカラー受信体にも定義できる。反対向きの入射を同じ履歴と数え得る |
| 荷の直接位相 | 二つの荷電端が実際に出会ったとき $(-1)^{q q'}$ | 補償された端と半周期を持つセクターに定義。通常の重力波は他層へ伝搬しない。位相は後の干渉に作用する |
| 独立スカラー交換 | 二つの受信済みの相対荷が同居するときだけ $J_{\rm pair}\varphi$ | 保存的な通常物質の直接線形源を対称性で抑制。質量・規格化・量子補正は未選別で、物質を含む弱場試験が必要 |
| 二信号の不一致 | 物質が受けた二つの信号上の $(1-\mathsf{Swap})/2$ | 一致した未知の純粋信号対を決して誤検出しない最大効果。混合状態の恣意的な分解を読まない |
| 多信号の不一致 | 物理的に集まる $m$ 自由度上の $1-P_{\rm sym}^{(m)}$ | 多重度は束縛状態・受信構造で決まる。同じ周辺密度行列でも全体相関で結果が異なる |
| あらゆる一重項を交換 | 実在する四つの $j=2$ 放射の全一重項で物質の五状態を交換 | 一個の角分布を保存。最大混合の入力でも四体状態は一般に変わる |
| 置換対称性で保護された交換 | $[22]$ が二重に現れる部分の重複度を交換 | 角分布に偏りのない任意の時系列で同じ作用。最大混合の量子ビットに対して四体の参照密度も保存 |
| 適合した五状態の交換 | 参照状態に整合した逆平方根フィルタと交換 | 五状態を完全移送する最大確率を達成。局所で参照状態を実装できる準備に限る |
| 順次放出 | 実交換の都度、源の量子メモリから次の放射へ等長写像 | 過去に逃げた放射に再作用する必要がない。必要な最大中間次元25、因果的な預入れと局所反跳が必要 |
| 層を保存 | 新しいラベルを既存の私的層に結合し、逆交換でも古いラベルを維持 | 直和での原理的な消去不能性は追加公理。近くの情報を思い出しやすい事実からは強制されない |
| 逆交換で消失 | 現実に逆遷移があったとき、古い層ラベルを捨てる | 消失率に新しい係数はない。熱平衡時には逆遷移の率を詳細釣合で制限できる |
| 受信のたびに置換 | 同じ物質自由度が新しい記録で物理的に置換された時点で古い層を統合 | 保持時間は次の実遷移の待ち時間で決まる。逆遷移だけで消える場合と異なる |
| 可逆な対照 | 振幅の異なる $y$ を閉じた系でコヒーレントに保持 | 同じ吸収スペクトルを与え得る。選択作用そのものの根拠にはならない |

選別条件は完全正値性、全確率1、物質が保持する参照への線形性、実受信、無信号性と通常の弱重力極限である。直接位相は閉じた相互作用のみでは不可逆性を生まないので、実交換の私的直和と組み合わせる。中央値や観測者の主観的な分解を当地の一個の状態から読み出す規則は遠方で選べる準備に依存し、候補から外した。対称性はある作用の下で最大の効果・保護される部分代数を特定するが、全候補のうち一つを強制しない。

## 四次元の量子場で物質の状態が運ばれる条件

真空相関を測定しただけでは「Aが放射になった」とはいえない。Aの一自由度と第三の参照をもつれさせ、終状態でそのもつれが放射と参照に残り、元のAには複製がないことを移送の判定とした。偏極パリティー一方の球面四重極にある磁気量子数は五つ。四粒子の回転一重項は、中間角運動量 $0,1,2,3,4$ で数えると五次元となる。どの一脚を測っても $I_5/5$ で、任意の一脚の消失を訂正できる。

偏りのないガウス場で、時間の違いから来る干渉は24個の置換の線形結合になる。回転一重項上の置換表現は自明表現一つと二次元表現 $[22]$ 二つ。したがって時間相関をどのように変えても二つのコピーを区別する量子ビットは熱的な放射の角度状態と独立である。任意の二つだけを重ねる準備で六つの互換を個別に取り出せるため、全時系列を通じて角度状態を保つ可逆操作の最大の行列ブロックは二次元となる。これは全ての非ユニタリー通信路の容量上限という主張ではない。二つの実際の四重極応答の間でこの自由度を丸ごと交換する。物質側の重複度と放射の空間の物理的同一視、交換できる因果点を仮定した。

六つを同じ場から受ける場合、最初の二つで層の厚みを測り、残りの四つへ交換する。比較側だけの不一致率は $d_o=2(1-v)/(5+v)$、$v=|K_{12}|^2/(K_{11}K_{22})$。同じ時系列の量子を二部位に割り当てているので、六体同時の成功確率はこの周辺確率と四体の確率の積ではない。六点の720個の置換を全て取り、検査する二脚を閉じる。時刻・頻度は不変の係数を手で設定せず、変化する場の正規順序共分散と空計数確率から決まる。通常の重力過程が前提で、適合する六量子受信体が自然形成される率までは含まない。

## 蒸発中の範囲と既存の量子重力

半古典的には受信率を同じシュワルツシルト質量で計算した。片パリティーの粒子流は $1.10256\times10^{-5}/r_s$。周波数分布、反射、ボース干渉を含み、24・720個の置換を計数する。実受信に応じて近傍の履歴で厚みゼロ、遠方で非ゼロが可能だが、遠方が必ずより厚いとは限らない。全く同じ信号と装置を受けた二人は同じ確率を得る。因果的な接触のない終端同士を比較する必要はない。

一個の粒子の角度上の情報には最大 $\log5$ の制約があり、四粒子の回転一重項を使うと四個合わせて最大 $\log5$ になる。ホーキング質量損失で全期間を積分すると後者は穴の面積エントロピー減少の4.644%以下。すべての磁気自由度を長いブロックで使っても18.577%以下。少数の物質相関の移送は可能だが、全体を説明するためには放射の数・時刻・周波数、別の多重極・粒子種、あるいは別の因果結合が要る。数と周波数も含む普通のガウス熱状態のエントロピー流束は、この部分波で失われる面積エントロピーの1.34905倍だった。この余地を利用する実際の交換作用の同定は残る。

落下側では薄い層への付加交換がゼロなら、無限遠静止から落下する球対称な大質量穴の古典解は地平面から $2r_s/3$ の固有時間で原点へ至る。プランク曲率から先を含む量子解は求めていない。遠方では実際の物質自由度が既に外の記憶へ渡った場合にのみ、局所的な放射への移送となる。$2r_s$ から相対高度 $10^{-38}$ までの落下で利用できる遅延時刻は約 $177.67r_s$。この窓の通常の四重極流だけで六個以上が揃う確率は両パリティーを合わせても $6.53\times10^{-4}$ 以下。これより長く記憶を保持する源が必要になる。

行列模型では実際に計算できるBMNの中心調和振動子を用いた。異時刻の四重極を三種の二重トレースと二種の巡回トレースで縮約すると、真空からの応答と一量子占有からの応答を合わせて五次元を張る例を得る。真空だけの二組の時系列では数値階数3である。等時刻には対称性で1となる。SU(N) の非可換な内部力学での蒸発を示す計算ではない。ループ重力の量子四面体は同じ運動学を持つが、物質の受信を伴わない基底変更のたびに書けば反転の確率が $33/125$ に落ちる。因果集合では、伝達を過去から構成した正の核は、後から起きる事象で前の確率を変えない。全時空領域で選んだ真空の二点関数を即時の占有率とする案は最短の鎖でもこの性質を失う。CDTの反射正値な二段伝達行列だけから、放射の順序を持つローレンツ核はまだ求まらない。第11次元を層保持に使う案は残るが、四次元の重複度はそれがなくても成立する。

## 物質の共鳴極が自ら行う交換

四体の交換を外から指定するという弱点に対し、重力波が物質に散乱する際の実際のS行列を使う案も計算した。スピン2の物質と四重極波の散乱でスカラー共鳴が孤立すると、通常の弾性振幅は $S=1-P+sP$ である。$P$ は合成角運動量ゼロへの射影、$s$ はスカラーの部分波S行列である。私的選択の確率を $q=|1-s|^2/4$ とする。$D$ が実際に受けた相関の不一致を示すときにだけ、三つの経路振幅 $S\sqrt{1-qD},\sqrt q\,sPD,\sqrt q\,(1-P)D$ に異なる私的ラベルを付ける。非弾性チャネルがある場合には失われたフラックスも一つの終状態として含める。書込み頻度は作用で定義したこの確率と、当地で物質に到達する重力のスペクトル流から決まる。散乱位相がゼロになれば書込みも消える。$q^m$ を用いる規則も同じ対称性を持つので、唯一の規則という結論は得られない。

入射四重極が五方向に等方的で、比較用の受信物質と参照もつれを運ぶ自由度を独立に準備したとき、スカラーの弾性線で $q=1/4$ なら、厚み $d_o>1/6$ の側だけが放射ともとの参照とのもつれを運べる。$d_o=0$ の側はこの入射粒子だけを見ると、どんな入力に対しても参照とのもつれを失う。四重極の二つの物理的な受信で $d_o$ を測る場合、これはモードの重なりの二乗 $v<7/13$ に対応する。物質自体に残る情報も計算しており、もつれの完全移送ではない。さらに線の中心と裾では選択による変化の符号が逆で、平らな入射スペクトルで線全体を積分すると先頭の変化は相殺する。二つのヘリシティーだけの細い入射ビームで計算し直すと、薄い側にも放射へ行くもつれがある。受け取るモードの範囲は結論を左右する。

非相対論的な万有引力で束縛された二体系では、スピンなしの $3d\leftrightarrow4s$ は下準位が約627倍速く崩壊して使えない。一方、内部スピン2を保持する構成物の $1s$ は安定な五重項である。軽い側の最小限のスピン軌道結合を保つと $3d$ 上準位の全角運動量ゼロの極を分離でき、$1s$ への分岐比は $b=0.920896$。非弾性な $2s$ への放射も正規化に入れ、$y=2(\omega-\omega_0)/\Gamma$ として $y^2=4b-1$ では厚みの境目 $1/6$ が保たれる。物質の内部スピン、未計算の物質四重極の小ささ、背景潮汐・吸収・競合線幅の制約がある。現実に落下中のAを構成する全物質がこの準位系になるという仮定は採用していない。

円運動量を持つ単一のKK重力子でスピン2の標的を作ると、同じ次元縮約から通常のベクトルへの電荷 $e=\sqrt{16\pi G}\,\mu$ が生じる。中性の重い中心に束縛されたとき $3d\to2p$ の電気双極の幅が $0.0161061\,G\mu^3\alpha_g^4$ となる。重力四重極の幅は $\alpha_g^6$ なので、弱束縛ではベクトルが勝つ。孤立した一つのテンソル共鳴で、等方的な入射に対する境界を超える条件を満たさない。個々の円電荷では難しいという計算であり、円が層を保持する可能性や、層間の別種の相互作用までは排除しない。

同じ共鳴の作用を、時空計量を与えない順序付きの関係に移した。外部ポート $m$ 個と内部への戻り一つを持つ事象で $2{\bf1}{\bf1}^{T}/(m+1)-I$ を適用する。整数回の戻りを位相を保って加えると弾性への分岐 $b=1/m$ が得られる。二外部ポートでは準備した入射位相 $(-3-4i)/5$ で $q=1/8$、不一致の境界 $1/6$ が再現される。各戻りの時刻を永久に書けばこの振幅和は消える。この構成は局所作用を関係だけで実現するが、ポート数、状態、一般四次元の極限を選ぶ重みはまだ導いていない。

書込みの強さは、通常の部分波の位相を一度だけ通るコヒーレントな参照に対し、相互作用が無いときは暗く、一回で得られる最大の応答を選ぶという二条件の下で一意に $|1-s|^2/4$ になる。ただし、相関を運ぶ放射そのものを二経路に通して得る暗出力なら、確率にはスカラー成分の占有率も掛かり、二出力の平均は異なる通路となる。後者は同じ離調においていくら厚みを増してももつれを伝送できない。したがって独立な参照を持つ受信体またはS行列そのものから選択率を構成する根本法則を必要とし、普通の一回散乱でその新法則が自動的に実装されるとはいえない。

幅の狭いスピン付き物質線を、単一パリティーのホーキング部分波に等方的に整合させた場合、線中心 $\omega_0 r_s=0.7$ での弾性書込み率は $4.3611\times10^{-5}d_o\Gamma$。$\Gamma$ は物質作用から上で得た全幅である。非弾性の別出力はこの数に含めない。天体の遠方に置いた任意の小さな受信体の絶対率はその実際の開口と形状にも依存する。
