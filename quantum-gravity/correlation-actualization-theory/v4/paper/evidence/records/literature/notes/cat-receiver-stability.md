# 受信膜の揺らぎと、特異点の二つの内部の識別に関する原著

2026-11-24。SRC-1987–1992、RES-0158。[計算](../../derivations/DER-0158.md)・[前節の基礎文献](cat-contact-recoil.md)。各行の比較は引用した背景・自由度に限る。

| ID・原著 | 既知の内容と今回の使用範囲 |
|---|---|
| SRC-1987　Awata、Hirano、Hyakutake | 行列理論の膜と反膜で、非対角ゲージ場の不安定性と凝縮後の渦解を扱った。負の二乗振動数の存在自体には先例がある。ここでは時間と共に大きさが変わる二つの球で、受信時間と電荷を識別する物質の応答を計算した。[原著 v3](https://arxiv.org/abs/hep-th/9902158v3) |
| SRC-1988　Azuma、Bal、Nishimura | 交差するファジー球の安定性を、Chern–Simons項を含む縮約行列模型で解析した。第2.2–2.3節では二球間の場を二つのスピンの合成で分解する。今回、時間的な行列時計、質量変形のない球、負・正の両向き、物質端への有限時間の吸収を一緒に調べた。[原著 v3](https://arxiv.org/pdf/0712.0646)・[掲載誌](https://doi.org/10.1088/1126-6708/2008/03/035) |
| SRC-1989　Chu | 2026年のプレプリントで、球状のブロックと外部状態をつなぐ接線方向の極端偏極、二ブロックの作用、非線形項と不安定領域を扱っている。特に付録C・式(63)は今回の点状物質との対照に近い。本研究の差分候補は、反対向きの二つの呼吸する球で量子幅と履歴の端を追跡し、向きをそろえた候補で同じ電荷条件と吸収が残ることを調べた点にある。[原著 v1・本文](https://arxiv.org/html/2607.28746v1) |
| SRC-1990　Weyl | 線形変換の固有値の絶対値の積と上位特異値の積を比較した。二つの量子をもつれさせた純粋ガウス入力に対する識別限界で、上位一つ・二つの積に使う。[原著](https://doi.org/10.1073/pnas.35.7.408) |
| SRC-1991　Braunstein | 線形ボース系の変換を受動変換とスクイージングに分け、そこに含まれる不変量を調べた。ガウス忠実度の式はBanchiらの原著（SRC-1982）とも照合した。今回の二つの潮汐内部に一つずつ現れる伸長方向と最適化は行列作用からの計算である。[原著 v2](https://arxiv.org/abs/quant-ph/9904002v2)・[ガウス忠実度](https://arxiv.org/abs/1507.01941) |
| SRC-1992　Fuchs、van de Graaf | 密度演算子の識別距離、忠実度、二仮説の判別を結びつけている。純粋軌道に対する最良の識別と、一つの位置・運動量の線形結合を読む場合の下限を区別した。[原著 v2](https://arxiv.org/abs/quant-ph/9712042v2) |

二つの行列内部の外部潮汐は[SchwarzschildのPenrose極限](https://arxiv.org/abs/hep-th/0312029v3)を使う。二つの内部は本研究の行列状態であり、原著から一意に選ばれたものではない。先行研究の極端偏極、スピン合成、ガウス公式の適用範囲を以上のように照合した。今回の状態、有限時間の指標、量子対の相対伝播まで一致する先例はこの範囲では確認できていない。
