# SRC-1972–1977　スピン選択、保存された情報、損失のある偏極測定

2026-11-24。RES-0156・DER-0156。行列模型の荷電フェルミオン、交差する膜のカイラリティ、スピンによるトンネル抑制、対称性による量子情報の保護、光子損失による多体位相の消失を原著で照合した。

| 出典 | 原著で確認した内容と位置付け |
|---|---|
| 既登録のIshibashi・Kawai・Kitazawa・Tsuchiya、Blauほか | 通常の縮約超Yang–Millsの二次・四次・湯川項、光線近傍での平面波の潮汐は既知。本節はこれらを使った限定した物質作用と伝播の計算。 [IKKT v2](https://arxiv.org/abs/hep-th/9612115v2)・[Penrose極限 v3](https://arxiv.org/abs/hep-th/0312029v3) |
| SRC-1972　Steinacker・Zahn | 交差する行列ブレーンのカイラルフェルミオンの指標と摂動に対する安定性。今回の二つの横偏極のスピンは回転の生成子から得ており、四次元のカイラル零モードの位相的指標とは異なる。[原著](https://arxiv.org/abs/1309.0650) |
| SRC-1973　Ono・Austing・Tokura・Tarucha | 二つの量子ドット間の電流について、占有済みのスピン軌道が移動を抑える機構の観測。パウリ原理による阻止そのものは既知。行列の二偏極のガウス則は今回の模型に属する。[原著の抄録と書誌](https://pubmed.ncbi.nlm.nih.gov/12142438/) |
| SRC-1974　Knill・Laflamme | 量子雑音後の完全回復の必要十分条件。履歴を区別できる場合のスカラー効果による復号はその応用。対称性を用いる保護部分空間も既知である。本節は回転・鏡映が実際の行列作用・物質・CATのどの記録に残るかを調べた。[原著](https://arxiv.org/abs/quant-ph/9604034)・[Lidarほかの原著](https://arxiv.org/abs/quant-ph/9807004) |
| SRC-1975　Demkowicz-Dobrzańskiほか | モードと独立な損失を伴う二モード位相推定、固定光子数、全粒子を同じモードに置く重ね合わせの損失感度。ここでは光子分光精度を転用せず、二つのシュワルツシルト潮汐に合う行列内部から得た伝達率を使い、誤認を許さない有限回識別を計算した。[原著 v2](https://arxiv.org/abs/0904.0456v2) |

SRC-1976のBernevig・Orenstein・Zhangは、特定のスピン軌道相互作用のもとで、位置に依存する保存スピンを導いた。SRC-1977のGregoratti・Wernerは、環境測定から得た古典的情報を使えるときの量子誤り訂正を扱う。前者は本節の端とスピンの積、後者は記録した結果ごとの復号と比較した。[保存スピンの原著](https://arxiv.org/abs/cond-mat/0606196)・[環境測定を使う復号の原著](https://arxiv.org/abs/quant-ph/0209025)

横偏極、二膜と一点の行列、膜のフェルミオンと相対電荷、Pauli blockade、helicity・charge tagging、行列作用の対称性と量子訂正、特異点のPenrose極限と損失のある量子対の組合せを調べた。照合した原著に、半充填されたこの行列受信器の二円偏極・四次交換子を残し、落下中の期限に非零の電荷が出ながら、同じ電荷履歴が未知のヘリシティ二状態をどこまで保つかを計算した一致例は見つからなかった。これが本研究の新規性候補の範囲である。対称性の一般論、訂正条件、パウリ原理、角運動量保存、光損失一般の発見を主張しない。
