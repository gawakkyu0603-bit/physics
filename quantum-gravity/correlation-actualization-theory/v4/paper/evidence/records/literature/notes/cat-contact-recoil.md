# 接点の散乱、測定の仕事、内部の軌道記録の先行研究

2026-11-24確認。SRC-1978–1986。RES-0157。問題を、内部エネルギーを含む量子グラフ、運動量を支払う自律散乱、局所の検出による逆作用、行列ブレーンを通る物質に分けて原著を照合した。

| 文献 | 著者が扱ったことと今回の使用範囲 |
|---|---|
| SRC-1978　Kostrykin・Schrader | 自己共役な頂点条件からエネルギー殻ごとの散乱行列とユニタリー性を導いた。本研究では境界値のうちCATの電荷別等長写像でつながる成分を選ぶ。グラフの自己共役性や流れの保存そのものは既知である。[原著 v2](https://arxiv.org/abs/math-ph/9806013v2) |
| SRC-1979　Gnutzmann・Smilansky | 多モード量子グラフでモードごとに異なるしきい値とエバネッセント波を保った散乱を扱った。CATの各電荷区間で全内部準位を伝える計算に直接関連する。[原著 v1](https://arxiv.org/abs/2201.06963v1) |
| SRC-1980　Jacob・Esposito・Parrondo・Barra | 自律衝突における粒子の運動エネルギーと内部状態の変化を比較し、条件によって運動を仕事源として使えることを導いた。本研究の仕事源はCATの相対Dirac準位の運動で、衝突の慣性を行列の運動項から決める。内部・運動エネルギーの収支だけに新規性を置かない。[原著 v3](https://arxiv.org/abs/2108.13369v3) |
| SRC-1981　Yearsley・Halliwell・Hartshorn・Whitby | 正の運動量でも確率が逆向きに流れること、解析例と測定模型を検討した。原始的な到着率を量子流束に等置できない根拠として使う。[原著 v5](https://arxiv.org/abs/1202.1783v5) |
| SRC-1982　Banchi・Braunstein・Pirandola | 任意のガウス状態の量子忠実度を一次・二次モーメントから求めた。ここでは純粋ガウスの場合の二乗重なりだけを用い、実際のシュワルツシルト潮汐と整合する二内部から共分散を計算する。[原著](https://arxiv.org/abs/1507.01941) |
| SRC-1983　Berenstein・Dzienkowski | 行列と点プローブを結ぶ相対フェルミオンからブレーンの位置・向きや指数を求めた。球状行列と点の場所を照合する方法は先例がある。今回の法線質量と履歴の接続条件はこの原著の主張には含まれない。[原著 v2](https://arxiv.org/abs/1204.2788v2) |
| SRC-1984　Zener | 孤立二準位の線形掃引を解いた。今回の実効速度による数値は対照として使い、膜と量子場を含む有限時間の占有は直接計算した。[原著](https://doi.org/10.1098/rspa.1932.0165) |
| SRC-1985　Requist・Gross | 電子・原子核の分解で量子幾何テンソルに依存する運動エネルギーを扱った。行列物質の二準位を分解する尺度と、色数に応じた仕事・初期強度を今回計算した。[原著](https://arxiv.org/abs/1606.08424) |
| SRC-1986　Berenstein・Trancanelli | 平面波行列模型の二つのファジー球が相対運動するとき、交差付近の一部の揺らぎが不安定になり得ることを示した。本研究で求めた共に動く膜の吸収は指定した背景での摂動先頭項である。元論文と変形項や背景が異なり、ここでの安定性は独立に調べる必要がある。[原著 v2](https://arxiv.org/abs/1011.2749v2)・[掲載誌](https://doi.org/10.1103/PhysRevD.83.106001) |

元の十行列作用、ブラックホール特異点に沿った平面波の潮汐、測定と加法的保存量の制約はいずれも既知である。今回の具体的な差分は、同じ物質交差にどの反跳を使うとC3の漸近電荷がエネルギーを支払えるかを計算したこと、有限時刻の局所選択の仕事をその波束で定量化したこと、そして二つの行列内部を通る軌道から未知の偏極の回収限界を導いたことにある。検索で同じ組合せの計算は確認できなかった。世界での優先権や、CATに採用した接続の一意性は確定していない。[IKKT v2](https://arxiv.org/abs/hep-th/9612115v2)・[Blauほか v3](https://arxiv.org/abs/hep-th/0312029v3)・[小澤 v1](https://arxiv.org/abs/quant-ph/0112154v1)
