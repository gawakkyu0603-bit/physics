# SRC-1960–1964　行列膜の揺らぎ、平面波の真空と、ユニタリ伝播の識別

2026-11-24。RES-0153・DER-0153・VER-0140。関連する先行例は落下する行列膜と[Schwarzschild の光線近傍](../../verification/VER-0139.md)にも記録してある。

| 原著 | 原著に依る部分と今回調べた部分 |
|---|---|
| SRC-1960　Ishibashi・Kawai・Kitazawa・Tsuchiya | 十行列の通常作用と揺らぎ・スピン結合が基礎。CATの物質受信や、今回の二つの内部状態は原著の主張に含まれない。[原著](https://arxiv.org/abs/hep-th/9612115) |
| SRC-1961　Papageorgakis・Ramgoolam・Toumbas | 縮小するD0–D2束縛系のDBI作用の二次揺らぎと強結合になる領域を扱う。小さい球の揺らぎを常に線形化できるという根拠にはならない。ここでの全角モードの仕事は通常Yang–Mills部分の結果。[原著 v2](https://arxiv.org/abs/hep-th/0510144v2) |
| SRC-1962　Axenides・Floratos・Perivolaropoulos | 回転する球状・楕円膜の古典摂動、スピン分解の先例。今回の比較では回転枠のMajorana共分散に対し、直進と同じ古典エネルギーのもとで全角励起の上限を求めた。[原著](https://arxiv.org/abs/hep-th/0007198) |
| SRC-1963　Gibbons | 古典的な重力平面波中を伝播する量子スカラーで、真空からの粒子生成がないことの先例。今回の二つの行列コアにおける物理的な有限縦運動量の偏極転送を原著に帰していない。[原著](https://doi.org/10.1007/BF01629249) |
| SRC-1964　Acín | 二つのユニタリを理想的な並列使用で識別できる条件。3,878という値は今回の行列状態から計算した相対固有位相にこの判定を適用したもの。[原著](https://arxiv.org/abs/quant-ph/0102064) |

球そのものにはKabat–Taylor、Gauss状態によるBFSSの実時間近似にはBuividovich・Hanada・Schäferがある。[球状膜](https://arxiv.org/abs/hep-th/9711078)・[実時間計算](https://arxiv.org/abs/1810.03378)。Schwarzschild の逆二乗潮汐は既知である。[Blauほか](https://arxiv.org/abs/hep-th/0312029)。

関連文献は、縮小するファジー球の全角揺らぎ、随伴フェルミオンの準位交差、行列模型の回転膜、平面波の光円錐伝播、ユニタリの完全識別から調べた。今回の研究上の差分は、同じ始終配置での二つのフェルミオン仕事の階数依存、量子化した径の全時刻上限、両外部の行列と時計が一致する二つの局所状態での物質への転送を、このCAT作用の書込み条件と照合した点である。これらの数学的道具やフェルミオンの準位反転に初出を主張するものではない。
