# 回転電荷と重力係数に用いた原著　SRC-2135–2147

2026-11-24。[DER-0174](../../derivations/DER-0174.md)・[既出の太陽系測定](cat-tetrahedral-radius.md)。有限密度の位相作用、音響共鳴、量子補正、正則なスカラー・テンソル理論の集束条件には先行研究がある。以下は適用した箇所である。

| ID | 原著と適用した内容 |
|---|---|
| SRC-2135 | Sharon・Watanabeは \(4-\epsilon\) 展開の三次超ポテンシャルで、大きな保存電荷を持つ状態のスカラー・フェルミオンの分散および球面での行列式を計算している。付録Aが直接の比較対象。ここでは四次元の一つのカイラル場と固定半径の回転差を使う。[原著](https://arxiv.org/abs/2008.01106) |
| SRC-2136 | Martin・Vaughn §II の一般の超対称湯川結合の一ループ異常次元とベータ関数。\(W=Y s^3/6,\ Y=2y\) で本文の係数を照合。[原著 v4](https://arxiv.org/abs/hep-ph/9311340v4) |
| SRC-2137 | Camporesi・Higuchiの球面上のDirac固有値・縮退を三次元空間に使用。[原著](https://arxiv.org/abs/gr-qc/9505009) |
| SRC-2138 | D’Alessio・Polkovnikovが断熱的な量子応答から導いた慣性。時間に依存する外部せん断の運動係数に用いた。[原著 v2](https://arxiv.org/abs/1309.6354v2) |
| SRC-2139 | Kovtun・Shuklaの相対論的媒質の二微分の平衡応答と応力相関。静的曲率を読む原理の位置付けに使用。回転背景の数値を借用していない。[原著 v2](https://arxiv.org/abs/1806.05774v2) |
| SRC-2140 | Sonは零温度の相対論的超流動の位相作用を熱力学的圧力から決めた。二室の圧縮率と位相勾配エネルギーを決める入力。[原著](https://arxiv.org/abs/hep-ph/0204199) |
| SRC-2141 | Brandão・Schnitzerは狭い首を持つ音響共鳴器の漸近展開と端補正を求めた。開いた外部空間を扱う原著と、本文の閉じた二室の境界条件は異なる。[原著](https://arxiv.org/abs/2001.09353) |
| SRC-2142 | Colemanはスカラー場の電荷固定エネルギーと、自発的に局在する解を許すポテンシャルを研究した。ここでは質量のない正の四次項に個別の三次元スケール変換を適用した。[原著PDF](https://www.ift.uam-csic.es/sites/default/files/QBALLS.pdf) |
| SRC-2143 | Hochberg・Visserは喉を通る光の広がりとヌルエネルギー条件の関係を局所的に与えた。[原著](https://arxiv.org/abs/gr-qc/9802048) |
| SRC-2144 | Bronnikov・Starobinskyは正の非最小重力係数と正符号のスカラーについて、Einstein系への変換と二つの無限遠を結ぶ通路の制約を示した。有限の二室では本文の面積半径の増減条件を別に課す。[原著](https://arxiv.org/abs/gr-qc/0612032) |
| SRC-2145 | Podolsky・Auerbach・Arovasは振幅モードからGoldstone波への崩壊と線形応答を解析した。半径振動が二音波に減衰する機構そのものに先例がある。[原著](https://arxiv.org/abs/1108.5207) |
| SRC-2146 | Joyceほかは四次スカラー超流動について半径を一ループで積分し、状態方程式を求めた。今回の圧力には同じ回転状態のWeyl場も寄与する。[原著](https://arxiv.org/abs/2204.03678) |
| SRC-2147 | Huiほか §3 は回転する相対論的な四次スカラーの外線の規格化と音波の崩壊率を具体化した。ここで報告した係数は静止した有質量の振幅モードを入射状態とする。[原著](https://arxiv.org/abs/2312.08440) |

光と重力波の速度差の原著は \([-3\times10^{-15},7\times10^{-16}]\) を与える。Galileoの重力赤方偏移測定は実在の原子時計・軌道、Planckの \(H_0\) は指定した宇宙論の推定である。二室の \(10^{-5}\) は比較用の精度で、この時計部門の実験信頼区間ではない。[GW170817・GRB 170817A](https://arxiv.org/abs/1710.05834)・[Galileo](https://arxiv.org/abs/1812.03711)・[Planck](https://arxiv.org/abs/1807.06209)

この照合で区別できた今回の成果は、一つの行列射影での固定電荷の時計応答、非線形な曲率障壁を通じた電荷交換とその重力源の同時検査、同じ回転状態の空間曲率応答と時間的せん断応答の有限差である。一般の電荷固定法、喉の集束条件、スカラーの球面行列式には優先権を主張しない。この組合せの文献上の世界初は確定していない。
