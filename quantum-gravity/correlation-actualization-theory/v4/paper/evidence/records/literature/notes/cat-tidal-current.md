# 多数の層で共有する内部計量と、記録を運ぶ物質電流の原典

2026-11-24。SRC-2092–2104。第5巻付録O.2、[結果](../../results/RES-0170.md)。同じ物理量を扱う先行研究が何を導いたかを確認した。以下の比較から研究全体での優先権までは確定できない。

| ID | 原著で確かめた事項 | 今回の用途 |
|---|---|---|
| 2092 | Rotaの有限半順序集合における反転。[原著](https://webhomes.maths.ed.ac.uk/~v1ranick/papers/rota1.pdf) | 包含する部分空間を数え、大きい方から重複を引く。IIB側の原始性と電荷規約は[Kachru–Schulz–Trivedi](https://arxiv.org/abs/hep-th/0201028v2)、磁荷壁は[Kachruほか](https://arxiv.org/abs/hep-th/0205108)。 |
| 2093–2094 | トーラス上の磁束差から生じるカイラル零モードと多重度、その空間に働く離散対称性。[Cremadesほか](https://arxiv.org/abs/hep-th/0404229)・[Abeほか](https://arxiv.org/abs/0904.2631) | 通常の行列コンパクト化は[Taylor](https://arxiv.org/abs/hep-th/9611042)。保存電流のうち対になって消えない部分と、識別しない内部状態を選ぶ。 |
| 2095–2097 | 質量位相と誘起電流、有限速度の二準位掃引で現れる誤差関数、空間的な質量反転が支える局在状態。[Goldstone–Wilczek](https://doi.org/10.1103/PhysRevLett.47.986)・[Dóra–Moessner](https://arxiv.org/abs/1008.0531)・[Jackiw–Rebbi](https://doi.org/10.1103/PhysRevD.13.3398) | 無限線形掃引による較正、有限時間の非線形な四準位潮汐史と開端の物質での計算を区別する。半電荷と端状態の発見を主張しない。 |
| 2098–2099 | 自由フェルミオンの生成関数と、部分領域の相関行列による占有統計。[Klich](https://arxiv.org/abs/cond-mat/0209642)・[Peschel](https://arxiv.org/abs/cond-mat/0212631) | 同じ検出作用素で比較する最終電荷の分布、粒子・正孔の同時確率を計算した。 |
| 2100 | 開端の一次元ゲージ理論でGauss則により電場を物質の電荷の和に置き換える。[Martinezほか](https://arxiv.org/abs/1605.04570) | 四つの物質準位の正の電場エネルギーによる有限時間の補正を上から抑える。原著の実験でCATを試したという意味はない。 |
| 2101–2102 | 最低Landau準位へ射影した密度の形状因子と、環境に未知状態が漏れないための量子誤り訂正条件。[Girvin–MacDonald–Platzman](https://doi.org/10.1103/PhysRevB.33.2481)・[Knill–Laflamme](https://arxiv.org/abs/quant-ph/9604034) | 内部磁気並進を保つ個々の出力と、非零内部運動量を持つ放射を比較した。 |
| 2103–2104 | 無限遠で静止した点質量の動径落下から無限遠に届く重力波エネルギーとスペクトル。[Davisほか](https://doi.org/10.1103/PhysRevLett.27.1466)・[Mitsou](https://arxiv.org/abs/1012.2028v2) | 総エネルギーを指定帯域での量子数の保守的な上限に変換した。軟放射や蒸発全体の情報の上限には使わない。 |

この比較に対する本研究の寄与は、前節の49フラックス軌道における任意個の層の共有計量の整数計数と、落下する四準位を具体的な二端の電荷計に結び、同じ測定、有限時間、対称性、補償電流を揃えた計算にある。磁束を持つ物質が一般の星で用意されることは独立の仮説である。上の原著のいずれも、CATの不可逆選択を実証するものとして用いていない。
